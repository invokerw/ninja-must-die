# 角色忍术 · 第一批实现

2026-11-12。实现依据为[整体设计 4.4](OVERALL_DESIGN.md#44-忍术与武器)，替换岚织 / 烬锋的灰盒月蚀斩；本轮不新增角色解锁、剧情、武器、UI 布局或正式位图。

## 行为与数据

| 角色 / 忍术 | 施放 | 普通哨兵 | 首领基础伤害 |
| --- | --- | --- | --- |
| 影刃 · 月蚀斩 | 0.12 秒后一次前方区域判定 | 每目标 3 | 24 |
| 岚织 · 风羽阵 | 0.12 秒后首枚，间隔 0.12 秒，共 6 枚实际飞行的羽刃 | 每枚 1，单目标最多 6 | 每枚 4，全部命中共 24 |
| 烬锋 · 雷裂斩 | 0.12 秒后第一刃，间隔 0.20 秒第二刃 | 每刃每目标 2，合计 4 | 每刃 12，合计 24 |

三者均为 K 忍术，12 秒冷却、接受输入当帧保护 2 秒；空放也消耗冷却。忍术不打断翻绳 / 跳跃 / 身法，不刷新跳数、空中额度或 J 冷却。长按不在冷却结束时自动重复施放。

`ActiveSkillData` 保存稳定技能 ID、攻击模式、段数 / 间隔、每段普通 / 首领伤害和弹体参数。数据校验拒绝未知模式、非有限参数、不正的伤害 / 速度、非法段数及超过保护时长的出手序列；运行队列只保存在 `RunnerCombat`，不写回 `.tres`。模式分派在战斗模块，Player / 关卡不按角色 ID 分支。

风羽阵每次出手从前方 640×200 的可达区域选择最近的存活哨兵或正在交战的首领；挂绳时区域以钢索中心为准，空中以身体高度为准。目标锁定后羽刃从角色前方飞出，以 1400 px/s、最多 6 rad/s 转向，寿命 1.2 秒；无目标时向前空放，不在飞行途中扫描区域外的新目标。已选目标死亡 / 退出交战时回收，不穿透、不多目标重复结算。使用相对运动扫掠碰撞检查高速跨越，命中前不施加伤害。

雷裂斩每一刃使用当时角色位置的前方 640×200 区域，每刃每目标最多命中一次；第二刃可以命中仍在范围内的同一目标，也可以因目标离开范围而落空。两刃独立攻击 ID；羽刃亦每枚独立 ID，首领护甲 / 弱点按命中当帧结算。成长缩放沿用共用 J / K 舍入累计，不用动画或段数重复刷连击。只有实际击破哨兵或首领才增加击破 / 连击。

## 生命周期与显示

暂停冻结出手队列、羽刃飞行、冷却和保护。停止、死亡、终点、场景退出和首领击破清理后续攻击 / 弹体，重试使用原角色武器快照并新建冷却与队列；首领击破不能造成重复奖励。羽刃与武器 / 飞镖共用 32 个友方弹体上限。

HUD 和准备页读取资源中的真实名称，暂停与准备页滚动能力说明显示实际分段 / 伤害；现有布局与输入不变。风羽阵使用原生浅青羽形弹体，雷裂斩使用原生短时雷线，沿用原生忍术保护与反馈；本首版功能、原生特效与手感已于 2026-11-12 获用户“验收完成”确认，Android 实机仍待单独验收。

## 入口与验证

F5 → 行前准备 → 已解锁岚织 → 设为出战 → 关卡 / 首领练习。烬锋仍等待尚未开放的 1-3，可在隔离档案的共用启动器体验：

```sh
/Applications/Godot_mono.app/Contents/MacOS/Godot --path . \
  --script res://tools/run_sandbox.gd -- --character=thunder_guard --mode=boss --touch
```

复用 `test_combat.gd` 验证真实飞行 / 延迟、多段伤害、逐段护甲、前后方目标、暂停、停止 / 死亡 / 击破、超高速扫掠、静态资源隔离；`test_weapons.gd` 验证重试清空旧忍术队列；`test_ui_components.gd` 验证 HUD / 暂停名称与能力跟随角色。无新增测试场景。实际执行结果和截图见[本切片验证记录](../art/validation/combat/ninjutsu_v01/README.md)。
