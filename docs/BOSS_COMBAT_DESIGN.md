# 首领战斗扩展：飞镖球、武器与角色技能

> 版本：0.3 · 日期：2026-10-25 · 状态：v0.11 首轮已实现，已通过回归与实际战斗回放
>
> 基于 v0.10 原型扩展，本文数值已接入 v0.11。场景规则见 [小型首领](BOSS_ENCOUNTER.md)，角色规则见 [角色技能](CHARACTER_SKILL_DESIGN.md)。首轮仅保留安全侧基础飞镖球；额外高风险奖励球与第二阶段留待后续评估。

## 1. 要解决的体验问题

旧版机关鸢有 9 点生命，只有收招时才能受伤；月蚀斩每次造成 3 点伤害、冷却 12 秒。玩家的攻击决策基本只有“等核心变金，再按 K”，其余时间重复翻绳。护甲期间完全免伤，也让长时间躲避缺少输出进展。

本版让玩家持续做三类决定：翻到哪里接住攻击道具、何时用武器补伤害、把月蚀斩留给弱点爆发还是提前保命。移动继续是主操作，角色仍为一个主动技能和一个被动能力。

## 2. 《忍者必须死3》的参考与本项目取舍

官方资料分别讨论飞镖球伤害、武器技能冷却和忍术，说明它们是不同的战斗来源。例如 [2026 年 9 月维护公告](https://www.pandadastudio.com/m/news/202609221647138E8CC02F17C48D6DD8) 的“禁锢”效果独立调整这三类机制；[2026 年 4 月维护公告](https://www.pandadastudio.com/m/news/69df4deaaaefc) 中的特定卡牌把拾取飞镖球与主武器冷却关联起来。这些是特定模式 / 效果的规则，不是所有战斗的通用参数。

[官方 S10 赛季公告](https://www.pandadastudio.com/gl/5f2238ac5c3d4) 也分别列出忍术、武器技能、飞镖球与忍术能量。由这些机制得到的设计启发是：跑位可以产生进攻收益，武器与角色技能提供不同节奏，输出不必全部绑在一个大招上。这是对机制的归纳，不表示已实测其当前全部 Boss 或伤害占比。

本项目借鉴这套战斗分工：新增局内飞镖球与角色模块中的一个可更换主武器槽，保留 K 的时间冷却和踏影被动。角色模块负责装备选择、兼容校验和出战配置；武器提供 J 技能，首领只提供战斗目标。首版不引入忍术能量、装备成长、副武器、局内角色切换或战斗卡牌。影晶继续只影响收集、连击与评分。角色准备页、两把武器、更换与保存规则见 [角色模块与可更换武器](CHARACTER_WEAPON_DESIGN.md)。

## 3. 三条输出渠道

| 渠道 | 操作与当前参数 | 在战斗里的作用 |
| --- | --- | --- |
| 飞镖球 | 首领场内拾取后自动连续发出 3 枚飞镖，每枚基础伤害 2；不增加按键 | 持续小额输出，让躲避与捡取本身能推进血条 |
| 武器「弦月轮」 | J，6 秒冷却；0.24 秒内发出 3 枚刃波，每枚基础伤害 4；无无敌 | 在两次月蚀斩之间反复使用，选择即时补伤害或等弱点 |
| 可替换武器「贯星矛」 | 与弦月轮共用主武器槽和 J；8 秒冷却，蓄势 0.30 秒后发一枚长矛，基础伤害 16；无无敌 | 首轮即提供的另一种攻击节奏，验证更换能改变实际战斗行为 |
| 角色主动「月蚀斩」 | K，保留 12 秒冷却、输入当帧起 2 秒无敌、0.12 秒出招；首领战基础伤害 24 | 大额爆发与紧急保护，形成进攻 / 保命取舍 |

表内伤害只用于首领战的首轮平衡，不能直接照搬到现有 1 点生命的普通哨兵。普通跑酷段的月蚀斩仍按当前 3 点伤害与原关卡验收规则运行。

J 是武器槽的主动技能，不恢复旧版贴身普通斩击，也不增加角色专属主动技能数量。武器在角色准备页更换，开局锁定本局配置，暂停或重试不能临时换装刷新冷却；重试使用同一配置的新局初值。首轮仅在首领战开放 J 与飞镖球，先验证闭环，再决定武器是否延伸到跑酷段。进入战斗时给出短提示，武器首次开放时就绪；K 冷却继承跑酷段，不能通过进场刷新。直接首领练习时两者均就绪。

J / K 都需要一次新的按键按下事件，长按不自动重复；释放武器、飞镖或月蚀斩不锁翻绳、跳跃与影步，不刷新跳跃次数。武器和角色技能各自计时，可同时使用，单次按键只消耗一次自己的冷却。

玩家飞镖与刃波自动锁定当前首领，允许有限转向，使注意力留给跑位；必须实际飞到并命中受击形状后才扣血，不能拾取瞬间直接减血。伤害按命中时首领状态计算，允许玩家提前投射、让弹体赶上弱点窗口。每枚弹体最多造成一次伤害。

玩家攻击使用与敌弹不同的月光 / 金色外观。敌方齐射继续从屏幕右侧外发射，按预选固定方向并排飞完全程；新增玩家攻击不改变敌方发射源、瞄准、速度或间隙。

## 4. 护甲从完全免伤改为减伤

登场、死亡和取消状态不接受伤害；正式交战期间采用两档：

| 首领状态 | 受到伤害 | 反馈 |
| --- | ---: | --- |
| 蓄力 / 攻击，有护甲 | 基础伤害的 50% | 护甲火花，生命条小幅下降 |
| 收招，弱点开放 | 基础伤害的 100% | 金色核心、明显命中闪光与完整掉血 |

飞镖球整组为 3 / 6，弦月轮整组为 6 / 12，贯星矛为 8 / 16，月蚀斩为 12 / 24。所有单枚伤害都能整除，不需要通过逐次取整改变伤害预算。弱点窗口首轮继续保持 2.6 秒。

这样护甲期出手仍有收益，等收招可以打出两倍伤害；提前用 K 保护自己会牺牲爆发效率，但不会再出现“放了大招、Boss 完全不掉血”的空转体验。所有进攻渠道均按同一套护甲规则结算。

首轮不让武器或 K 清除敌弹，也不让攻击延长弱点、打断首领或重置其动作。玩家仍需处理已经发出的弹幕；击破后的既有场面清理规则继续生效。

## 5. 飞镖球如何让移动参与输出

- 每个约 4.25 秒的首领动作循环安排一组基础飞镖球，放在该招结束后的可达安全线路上。首个球用于引导拾取，后续上 / 下侧按招式编排。
- 球使用独立的旋转三刃图标与轮廓，不能和影晶混淆；不计入原路线的 50 个影晶，也不靠拾取数量额外刷分或连击。
- 基础球在钢索附着身位内可取，不要求三段跳。球出现前至少可见 1.2 秒，不能出生在角色身上。
- 飞镖球固定在世界坐标，玩家向前经过；错过后离屏回收，不补发、不累计成场景垃圾。拾取后短时间依次射出，不建立弹药背包。
- 首轮仅保留每循环一个基础球，没有额外空中奖励球。安全路线靠普通翻绳即可完成，不要求影步或 K 无敌；漏球仍可用武器与角色技能完成战斗。

球不回复生命、不改变 K 冷却，也不恢复跳跃次数。空中奖励球留待真人试玩后再评估，不能用额外球掩盖基础攻击手段的不足。

## 6. 一段实际游玩节奏

1. Boss 预警上侧横扫，玩家下翻躲避；下侧线路出现基础飞镖球。
2. 玩家拾取后自动发出飞镖；此时即使护甲未退，命中仍能扣血。
3. 核心变金，玩家按 J 发射弦月轮，再视 K 是否就绪决定是否接月蚀斩。
4. 下一招预警下侧，玩家上翻继续避让，武器进入自己的短冷却。
5. 后续平射来袭，玩家可以走间隙保留 K，也可以用 K 的 2 秒无敌救急，同时打出减伤后的攻击。

熟练玩家把武器和 K 的命中尽量放进弱点，并持续收取基础飞镖球；初学者优先躲避、及时用武器、把 K 留作补救。两种打法都应能通关，区别主要体现在战斗时间与受击数。

## 7. 首轮数值与时长目标

首领生命从旧版 9 点重新标定为 **180**，配合上表三种伤害一起调整；不能只扩充血量。攻击保持当前 1.2 秒预警、0.45 秒生效、2.6 秒收招，先固定招式以便对照新输出的手感。

这组值已用于首轮回放，真人手感仍待持续验证。目标是一般玩家使用三种渠道约 30～45 秒完成首领战；熟练玩家约 25～35 秒；更保守的躲避与保命打法约 45～70 秒。没有强制超时，不以大招必用次数作为通关条件。

粗略预算：弱点约占循环 61%，随机时机命中的平均倍率约 0.81；武器理论基础输出 2 点 / 秒，K 为 2 点 / 秒，每循环一个基础球约 1.41 点 / 秒，合计约 4.36 点 / 秒的平均实际输出。180 点生命的持续输出估算约 41 秒；开局就绪、对齐弱点、漏球与弹体飞行都会改变结果。这不是实测通关时间，也不能用这个平均数替代真实回放。

当前首领评级基础时长为 40 秒，完整关卡为 100 秒。两条完整路线回放约 98.0～98.4 秒，均无伤收齐 50 个影晶。首领奖励仍只结算一次，玩家弹体的实际击杀共用同一个死亡入口。

## 8. HUD 与反馈

保留角色被动与 K 原区域，增加一个相邻、明显较小的 J 武器冷却位，分别显示“弦月轮 · 3.2s”和“月蚀斩 · 就绪”。J 的名称、图标和总冷却读取本局角色装备，可变为贯星矛；不能在 HUD 或首领里硬编码弦月轮。角色被动不增加按钮，画面中不恢复能量条。

飞镖球的自动发射只需角色旁短促三刃亮起，不添加第三个可按按钮。首领护甲期 HUD 在动作提示后标注“护甲减伤”，弱点期写“弱点开放 · J / K 爆发”，避免沿用“护甲未破”的完全免伤提示。

命中火花区分护甲与弱点，声音按一组攻击限频。飞镖与武器的常规命中不叠加屏幕震动；K、真实受伤和首领击破继续使用现有较强反馈。音效 / 粒子 / 震动 / 闪光四个设置分别生效。

## 9. 实现顺序与验收

第一轮实现一个完整小切片：角色模块的可更换武器槽、两把武器、准备页与装备保存、J 技能、玩家投射物、基础飞镖球、护甲减伤和首领血量重标定。同步处理出战快照、HUD、死亡 / 重试清理与击杀归属。继续使用当前三种首领攻击，不把新输出与第二阶段难度同时上线。

本轮验收覆盖：

- J / K 冷却独立，均不中断既有移动；同帧使用没有重复施放或丢失无敌保护。
- 角色准备页能更换两把武器，重启后恢复选择；开局与重试采用一致的配置快照，暂停不能换装重置冷却。
- 三条渠道在护甲与弱点命中时按预期结算；跨窗口飞行取命中时倍率，单枚不重复伤害。
- 飞镖球可在基础身位 / 二段跳下收集，不改变影晶数量或全收集路线；漏球后仍可继续战斗。
- 玩家弹体、敌方弹体、首领和拾取物分层；攻击不误伤玩家、不清空完整飞行中的敌弹。
- 任意来源击杀只触发一次死亡、一次击破与一次结算；首领死亡后在途友方弹体不再增加伤害、连击或击破数。
- 暂停冻结冷却、自动连发队列、弹体、拾取物与首领；死亡 / 结算清空它们，重试恢复场景初值，既有反馈偏好继续保留。
- 武器单用、K 单用、飞镖球加武器、三渠道混用分别完成真实回放，记录时长与伤害分布。三渠道混用明显缩短等待时间，K 仍有爆发价值。
- 原控制、拾取、角色技能、敌方投射物、路线、首领与反馈七套回归按新规则更新后继续通过，并完成实际图形与操作检查。

首轮真实回放（包含登场和退场）：

| 配置 | 用时 | 实际伤害 K / J / 飞镖球 |
| --- | ---: | --- |
| 弦月轮 + K + 基础球 | 38.60 秒 | 72 / 58 / 50 |
| 贯星矛 + K + 基础球 | 34.30 秒 | 72 / 64 / 44 |
| 仅弦月轮，无球 | 123.60 秒 | 0 / 180 / 0 |
| 仅 K，无球 | 93.27 秒 | 180 / 0 / 0 |
| 弦月轮 + 基础球，不用 K | 64.10 秒 | 0 / 94 / 86 |

第二轮再评估半血后的两波固定方向齐射或上下横扫连段。每一段都需完整预警与普通移动可行解；新增难度不得要求 J / K 冷却恰好就绪。更多武器效果、装备成长、副武器 / 战中切换和能量大招留待基础装备与战斗闭环验证后另行设计。
