# 成长与消费

2026-11-06：当前是准备页内的功能占位。经济事务与补给生命周期已有自动回归，商店整体尚未达到玩法 / UI 验收条件。设计依据为 [整体设计第 9～10 节](OVERALL_DESIGN.md#9-局外成长)，存档规则见 [成绩与存档](SAVE_SYSTEM.md)。

## 已实现与验证

- `EconomyService` 计算逐级成长价格、商品价格、唯一秘卷购买、补给库存上限（每种 9 件）及交易 ID / 消费 run_id 去重。
- `PlayerProfile` 提交扣钱、成长 / 库存和回执；写入失败保留同一份草稿并阻止新购买、配置切换及正式局，重试保存不再次收费。较新版本禁止经济修改，局内 / 暂停时配置冻结。
- 缺失的新字段按空成长 / 空库存迁入；JSON 整数值浮点数可回读，负数、小数、布尔、字符串、非有限数和已知字段越界拒绝写入 / 读取，损坏主文件恢复整份备份。保留未知扩展。
- 成长快照与共享资源隔离，护体增加本局最大生命。护身符挡第一次有效伤害但计受击，回春药在存活且生命降至 1 时恢复 1 点，仅触发一次，不能救活致死伤害。
- 正式场景完成关卡构建后、激活玩家前保存所选补给消费；重试清除旧补给效果，默认不续带。免费练习不扣库存，不激活准备页选中的正式补给。

## 自动验证

复用正式场景，无新增测试场景：

```sh
godot_bin=/Applications/Godot_mono.app/Contents/MacOS/Godot
"$godot_bin" --headless --path . --fixed-fps 60 --log-file /tmp/ninja-economy.log --script res://tests/test_economy.gd
```

预期 `ECONOMY_PASS` 和退出 0。`tests/test_profile_persistence.gd` 另验证独立进程间的成长、购买后库存、铜钱和消费回执恢复；先 `--write` 成功后再执行读取。测试使用 `.godot/` 中隔离档案并清理，不触碰玩家正式存档。

经济套件已加入打包工作流的串行清单；修改清单不代表远端 CI 已运行。具体本轮本地结果以交付记录为准。
