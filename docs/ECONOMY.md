# 成长与消费

2026-11-06：商店已从准备页覆盖层拆为独立的“山路行商”界面，概念 v02 已获用户通过。入口为 F5 → 山路行商，场景 `res://scenes/ui/shop.tscn`，Esc / 返回准备可退出；确认弹层中 Esc 先取消交易。经济事务、商店交互与补给生命周期已有自动回归，最终用户视觉、Android 实机和下列玩法缺口仍待完成。设计依据为 [整体设计第 9～10 节](OVERALL_DESIGN.md#9-局外成长)，存档规则见 [成绩与存档](SAVE_SYSTEM.md)。

## 已实现与验证

- `EconomyService` 计算逐级成长价格、商品价格、唯一秘卷购买、补给库存上限（每种 9 件）及交易 ID / 消费 run_id 去重。
- `PlayerProfile` 提交扣钱、成长 / 库存和回执；写入失败保留同一份草稿并阻止新购买、配置切换及正式局，重试保存不再次收费。较新版本禁止经济修改，局内 / 暂停时配置冻结。
- 缺失的新字段按空成长 / 空库存迁入；JSON 整数值浮点数可回读，负数、小数、布尔、字符串、非有限数和已知字段越界拒绝写入 / 读取，损坏主文件恢复整份备份。保留未知扩展。
- 成长快照与共享资源隔离，护体增加本局最大生命。护身符挡第一次有效伤害但计受击，回春药在存活且生命降至 1 时恢复 1 点，仅触发一次，不能救活致死伤害。
- 正式场景完成关卡构建后、激活玩家前保存所选补给消费；重试清除旧补给效果，默认不续带。免费练习不扣库存，不激活商店选中的正式补给。
- 独立商店提供共修 / 秘卷 / 补给 / 外观分类；外观为空状态，不上架未实现商品。共修展示真实下一档价格、当前 / 升级后值、累计上限和前置条件；秘卷支持购入后免费装备 / 卸下；补给显示库存及单局限一件的明确携带 / 取消入口。
- 每次付费先确认商品、花费和剩余余额；确认后重新核对档位、价格、库存和余额，重复确认不重扣。存档失败展示待保存余额与重试，冻结新交易 / 配置；重试只保存同一草稿。未来版本档案只读。
- 商店复用 `ScreenLayout`；按钮、动态字段与状态由 Godot 绘制。图标为概念通过后生成的透明图集；概念图没有作为背景接入。任务卡与截图见 [商店 UI 验收记录](../art/validation/ui/shop/v02/README.md)。
- 2026-11-06 用户通过通用 UI 概念后，商店迁移到 [通用主题与首批控件](UI_DESIGN_SYSTEM.md#10-首批原生控件与接入边界)：按钮 / 面板共用样式、持久待保存 / 只读标识、统一购买弹层。确认初始焦点为“取消”，Tab 在两个操作间循环，Esc 取消后返回原操作；经济事务规则不变。此为新基础样式，历史商店截图继续保留，最新证据见通用 UI 任务卡。
