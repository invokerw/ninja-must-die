# 音效、粒子与冲击反馈

> 版本：0.3 · 日期：2026-10-25 · 对应游戏设计 v0.12

## 操作与开关

准备页与局内右上角“设置 F2”或 `F2` 打开体验反馈面板，音效、粒子、画面震动和冲击闪光可分别关闭。`M` 可随时静音 / 恢复音效；暂停与结算时也能操作。关闭开关立即停止对应反馈，不影响其他选项。四个开关与 M 静音都自动保存至 `user://save.json`，重试与重启后保留。保存失败时开关仍即时生效，面板显示提示与“重试保存”；装备和成绩的待保存更改也一起写入。

设置面板不锁住跑酷输入。需要暂停调整时先按 `Esc`；按钮不接收键盘焦点，因此点击设置后 `Space` 仍按原规则翻绳或跳跃。冲击闪光开关控制本轮新增的屏幕色调反馈，角色原有的保护光圈、受伤闪烁和危险预警仍表达游戏状态。

准备页与局内共用 `FeedbackSettingsPanel`。`PlayerProfile.current()` 首次读取存档并应用合法布尔值；后续重试使用当前运行值，不在每次创建场景时重新读取磁盘。设置的类型校验、备份与跨进程验证见 [成绩、设置与存档](SAVE_SYSTEM.md)。

## 事件与表现

| 触发 | 声音 | 视觉 |
| --- | --- | --- |
| 实际起跳 / 空中追加跳跃 / 落绳 / 翻绳 | 短促的上扬、落点或翻转音 | 少量金色碎屑 |
| 实际影步 | 风切音 | 向后散开的金色拖尾 |
| 影晶收集 | 轻响 | 金色碎屑 |
| 月蚀斩施放 / 斩击 / 冷却结束 | 蓄势、风切 / 冲击、就绪提示 | 金色碎屑；斩击伴随轻微震动 |
| 机关、哨兵或远程来袭进入预警 | 上侧高音、下侧低音 | 保留原有侧别、箭头、金线与 HUD 预警 |
| 整波齐射发射 | 一次发射声 | 保留三枚独立飞弹，不逐弹叠加发射声 |
| 受到实际伤害 | 低沉冲击音 | 朱砂火花、轻微震动、短暂低强度色调 |
| 被保护的接触 | 清脆接触音 | 浅色碎屑；不会误报玩家受伤 |
| 武器施放 / 飞镖球拾取 | 一组短发射声 / 拾取声 | 少量暖金碎屑，不增加屏幕震动 |
| 首领护甲命中 | 清脆护甲声 | 少量浅色火花，生命按减伤后数值下降 |
| 普通哨兵击破 | 碎裂音 | 朱砂碎屑、轻微震动 |
| 首领登场 / 横扫 / 弱点开放 | 各自独立提示 | 保留首领形态与核心提示；开放弱点时增加金色碎屑 |
| 首领首次降至半血 | 复用登场音，音高为 1.25 倍，仅一次 | 橙红碎屑；强化血条与脉动外环持续表达状态 |
| 首领弱点命中 | 短冲击音 | 金色命中碎屑；普通飞镖 / 武器命中不震动，K 斩击保留原反馈 |
| 首领击破 | 低沉碎裂音 | 金色碎屑、最高 5 px 震动、短暂暖金色调 |
| 通关 / 失败 | 独立短结算音 | 清除局内粒子与冲击效果，进入原有结算 |

仅成功执行的动作触发反馈；冷却中重复按技能不会再次播放施放反馈。预警按进入状态触发，不按每帧重播；同波首领齐射只播一次预警与一次发射声，半血双波各自独立预警。强化音效与粒子分别遵循设置开关，血条和外环继续表达战斗状态。首领练习会取消跳过路线中的远程发射源，避免旧预警先响起。

## 画面与判定

粒子以世界坐标存储，在单个绘制节点里绘制并回收，最多 192 个，单粒存活约 0.30～0.52 秒，不为每次事件新建节点。碎屑不提供碰撞，也不共享游戏随机状态。

震动通过第 2 层画布的屏幕采样着色器处理最终世界画面；世界和画外发射源在下层，HUD 在第 3 层保持稳定。它不修改相机位置 / 偏移、画布坐标换算、角色位置、碰撞体或物理时间。普通冲击约 1.8～3 px，首领击破最高 5 px；闪光色调最高混合 12%，约 0.16 秒消退。

因此固定方向投射物的出生点与速度不受开关影响，弹道间隙和动作反应时间也不改变。关闭震动或闪光只移除对应效果，仍保留危险物本身的提示。

## 播放与生命周期

`PlayerController.feedback_requested` 将已结算事件传给当局的 `RunFeedback`，敌人通过绑定的玩家发出事件，避免多个视口或玩家夹具串音。`RunFeedback` 随场景释放，不使用跨关卡持有临时状态的全局单例。

武器施放、飞镖球拾取、护甲 / 弱点命中复用现有短音效，并按事件限频；未增加磁盘音频数量。21 个原型合成音效及可复现生成器见 [音效说明](../audio/README.md)。局内声部固定为 8，结算独立使用 1 个；重要预警与受击可以替换低优先级声部。普通提示为 -16 dB，拾取为 -19 dB，重要事件为 -12 dB，结算为 -10 dB；近距离重复拾取 / 击破至少间隔 0.06 秒，保护接触至少间隔 0.18 秒，控制连续重叠。

暂停冻结粒子、限频计时和冲击计时，并暂停局内音频；继续后恢复。停止或死亡立即清理局内反馈，成功 / 失败音由可在暂停状态下播放的独立声部负责。重试停止并释放旧播放节点，重建空的粒子、计时器和关闭的设置面板。

## 验证

`tests/test_feedback.gd` 覆盖导入音频、真实动作与冷却完成事件、上 / 下侧首领预警、整波发射次数、护甲与受击区别、独立开关、暂停 / 恢复、结算和重试，以及持续事件中的粒子与声音节点上限。开关震动与闪光前后，真实齐射的三个出生点和三个速度向量逐项完全相同。

无显示测试验证资源和事件而不启动输出混音，避免高速模拟退出时仍有待处理播放。去掉 `--headless` 可额外检查实际音频暂停 / 恢复与暂停后的结算播放。Windows Godot 图形检查设置面板、金色碎屑、技能与受击色调，分辨率为 1280×720 和 1600×900。

存档专项额外验证准备页、暂停与结算中的设置保存、M 与按钮同步、失败重试和新进程恢复。控制、拾取、角色技能、投射物、原路线与首领专项继续通过；四条跑酷路线的时间和收集结果保持一致，两个完整流程按新首领伤害规则约 98.0～98.4 秒无伤全收集通关。新增武器专项也覆盖暂停时的蓄势 / 连发冻结与首领击破清理。十分钟首领模拟与反馈压力检查只验证逻辑和节点上限，不代表移动端图形性能验收。
