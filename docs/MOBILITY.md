2026-10-30 已接入统一身法底座。2026-11-12 正式准备页已支持角色预览和确认出战，第一关通关后可选岚织；烬锋仍通过共用灰盒启动器体验。章节地图、前两关、星级 / 铜钱和商店已接入，剩余阶段边界见 [实现拆分](IMPLEMENTATION_PLAN.md)。

| 角色 | Shift / 触屏身法键 | 参数与限制 |
| --- | --- | --- |
| 影刃 · 踏影 | 跳、跳、身法，追加第三跳 | 初速度 -500 px/s；每次离绳一次，无保护。第三次按跳跃无效，提前点按不排队 |
| 岚织 · 御风 | 空中按住，下降时减速 | 下落上限 120 px/s；每次离绳累计 1.2 秒。上升不消耗，松开再按继续剩余额度 |
| 烬锋 · 雷闪 | 钢索或空中点按短冲 | 1000 px/s，持续 0.18 秒，前 0.12 秒保护，冷却 6 秒；同次滞空最多一次 |

三名角色共用 320 px/s 跑速、1800 px/s² 重力、-680 / -548 px/s 基础二段跳和 3 点生命。所有普通关主路线继续以基础二段跳可通过为前提。岚织 / 烬锋的局内动作仍使用青绿 / 橙色占位着色；风羽阵和雷裂斩的独立攻击序列已接入，规则及验证见[角色忍术](NINJUTSU.md)。触屏身法按钮暂复用原位移图标，名称与可用状态读取实际角色运行时。

## 练习入口

正式影刃跑酷练习仍可打开 `scenes/practice.tscn` 按 F6。灰盒使用共用启动器：

```sh
/Applications/Godot_mono.app/Contents/MacOS/Godot --path . --script res://tools/run_sandbox.gd -- --character=wind_scout --mode=parkour --touch
```

角色可选 `shadow_runner` / `wind_scout` / `thunder_guard`，模式可选 `parkour` / `boss` / `full`；按 F3 切换触屏预览。角色与武器快照在重试时保留。启动器使用独立临时档案，练习纪录、设置和完整关卡结果都不会写入正式存档，正常退出清理临时文件；正式准备页现已接入角色选择：岚织须完成 1-1 后设为出战，烬锋仍锁定并等待 1-3；启动器继续用于隔离档案下的三角色灰盒体验。

两个按角色复制的包装场景已由此入口替代。后续新场景、人工验收和清理遵循 [测试场景规范](TEST_SCENES.md)。

## 数据和运行时边界

- `MobilityData` 配置实现 ID、点按 / 按住模式、保护、冷却、空中次数和私有参数。加载时校验未知实现、缺失参数、非有限数和数值范围。
- `MobilityRuntime` 管理当局额度、滑翔时长、位移、保护和冷却，通过标准方法输出速度与垂直冲量。Player 不按角色名称或身法 ID 分支。
- `CharacterRegistry` 映射稳定角色 ID。`CharacterData` 添加身法、故事身份、解锁标识和占位颜色；新角色不要求配置旧被动。旧踏影被动可只读迁移为身法，且不增加基础跳数。
- `RunLoadout` 深拷贝角色、身法和武器。重试复制规则版本及嵌套成长 / 道具预留快照，运行计时仅存在于 runtime，不写回 `.tres`。
- `RunInput` 提供 `mobility_just_pressed` / `mobility_pressed` / `mobility_just_released`。旧 `dash` 保留一个版本作为同一身法的别名，没有额外共享冲刺入口。
- `PlayerTuning` 只保留共通移动参数；第三跳、滑翔和短冲数值属于角色身法资源。武器与忍术冷却独立。

## 输入与生命周期

同帧“第二跳 + 踏影”只执行第二跳，踏影要求新的身法按下事件。同帧“起跳 + 雷闪”允许先起跳再短冲，不额外消费跳数。绳下第三跳 / 御风不能直接发动；绳下雷闪保持下侧。

御风在快落、受伤、落绳、暂停或失焦时取消。暂停冻结时长和冷却并清除按住状态，恢复后需重新按住；受伤也要求重新按住。雷闪期间的翻绳和快落意图在短冲结束时执行，暂停 / 失焦会清除尚未执行的意图。落绳恢复空中资格但保留雷闪冷却。停止、死亡、结算和重试清空身法运行状态与保护。

雷闪沿真实玩家胶囊的完整移动路径检测机关、哨兵和影晶，避免仅检测位移端点。敌弹继续使用已有相对运动扫掠；伤害保护不影响拾取或终点，坠落仍会失败。旧存档格式、角色和两把武器的 ID 保留，不改存档版本。

## 验证

`tests/test_mobility.gd` 覆盖三种身法的配置、旧被动迁移、深拷贝、短触摸边沿、同帧优先级、累计滑翔、保护与冷却边界、位移沿途机关和拾取、暂停 / 失焦 / 停止、灰盒暂停布局和重试。

`tests/test_level_route.gd` 回放四条跑酷练习路线和四条含首领的完整路线。三名角色均可不使用专属身法走主路线，95.90 秒完成整关，0 受击、50 / 50 影晶；影刃另验证身法第三跳替代路线。触屏专项使用真实多指事件验证第三跳、御风按住 / 松开、雷闪、J / K、暂停、菜单与安全区域。

新增专项已加入发布 CI 的 Godot 回归列表。当前本地检查使用 macOS Godot 4.7；Windows CI 和 Android 实机不计作本地已完成验收。身法手感、占位美术和 Android 输入延迟仍需实际试玩。
