# 《影刃疾行》整体设计方案

> 版本：方向基线 0.3 · 2026-10-30
>
> 范围：角色、故事、章节与难度、关卡选择、三星评价、奖励、成长、商店及实施顺序。
> 故事基调、角色差异方向、三星与无伤印方向已确认；本文描述下一阶段的目标设计，不表示相关功能已经实现。现有运行规则仍见 `GAME_DESIGN.md` 等文档；发生冲突时，本文用于指导后续改版，不能据此认定旧功能已经变更。

## 1. 已确认方向与本稿建议

用户已确认：

- 三名角色以“三段跳 / 二段跳加滑翔 / 二段跳加冲刺”形成明显差异。
- 取消所有角色共享的影步，将冲刺归到特定角色。
- 所有角色共用一个“身法”键，分别发动第三跳、滑翔、冲刺。
- 局外采用适度数值成长：有少量生命与伤害提升，操作仍决定三星，零强化可以通关主线。
- 世界观扩大为“九域灯阵、天穹裂隙与失落文明”的长篇主线；第一章仍从一条送灯驿路切入。
- 故事基调确定为神话史诗：个人任务逐步牵连九域秩序、古神遗产和被抹去的第十盏灯。
- 三星不要求无伤；无伤单独记录为“无伤印”，可以展示并提供一次性奖励。
- 增加有难度曲线的第二关、故事背景、关卡地图与历史星级、通关奖励、成长、商店和代币消耗。

下列内容是可讨论的具体建议：角色新名字与故事、第一章五关结构、解锁节点、评分公式、所有价格与技能参数。参数用于建立可检验的初始模型，尚未经过真人试玩。

第一阶段产品目标：做完一个约 20～40 分钟首次游玩体验的章节，包含学习、数次重试和准备操作；熟练玩家五关纯通关用时约 8 分钟。全章三星和角色路线熟练另提供重复挑战空间。时长均为设计目标。

## 2. 核心循环与难度分层

```text
关卡地图查看目标与历史星级
  → 选择角色、武器、成长配置和可选道具
  → 读图、翻绳、跳跃、运用专属身法
  → 通关结算星级与铜钱、推进剧情
  → 解锁下一关 / 同伴、进行少量强化
  → 继续故事，或回来挑战更高星级
```

同一关分三种目标，不必让每个玩家在首次通关时全部完成：

| 层次 | 玩家目标 | 设计要求 |
| --- | --- | --- |
| 通关 | 活着抵达终点或击破首领 | 零强化、无道具、任一已解锁角色都存在可靠路线 |
| 三星 | 综合收集率、受击次数和完成结果达到分数线 | 允许偶尔失误；高分仍奖励稳定路线与较高收集 |
| 无伤印 | 全程没有有效受击，独立于星级 | 作为徽记、结算亮点和一次性奖励，不降格为第四颗星 |
| 精通 | 全收集、个人最速、特定角色路线 | 以徽记和纪录展示，不阻挡主线、不提供必需战力 |

难度主要来自预判、动作衔接、路线取舍和已学机制的组合。成长提供容错和缩短首领战的帮助，关卡不根据玩家装备动态增加生命或机关速度。

## 3. 故事：九域灯海

### 3.1 世界与主线

世界由九个相互悬接的“域”组成。每个域不只是地理区域，也承载一种维持世界的神性法则：鸣灯域守护火种与记忆，云阙域守护风路与远行，沧潮域守护誓约与归航，赤炉域守护锻造与战争，玄木域守护生长与血脉，镜川域守护映照与真伪，沉渊域守护梦境与亡魂，寂原域守护终结与归墟，星垣域守护观测与天命。

远古时代，九位“执灯神相”以自身神性铸成九座天灯，把九域从混沌中分隔出来。后世只记得神相的称号和祭仪，忘记了他们为何要把世界分开。九域之间原本由天灯阵维持航路、季候和亡魂归途；灯阵熄灭的地方，现实会出现重叠，山会倒悬，河流会流入天空，记忆也会被雾吞掉。

这套世界观借鉴古代志怪的异兽谱系、祭灯传统和远行史诗的“逐站归来”结构，再重新解释为一个原创的移动世界：灯不是需要膜拜的神明，而是古神留下的“秩序锚”。它照亮道路，也把九域分隔成彼此可控的边界。谁掌握灯阵，谁就能决定哪些地方相遇、哪些历史被遗忘。

第一章发生在北境“鸣灯域”。这里的山城靠山间灯阵驱散夜雾，运送灯芯的驿路铺在断崖之间，忍者依靠钢索穿行，也是大规模断桥后仍能使用的交通线。

一次“熄灯之夜”后，北境三座天灯同时暗下，护城机关失控，运灯队失联，雾正沿钢索驿路逼近山城。主角影刃接到最后一项差事：把备用灯芯送往主灯台，重建沿途的传灯节点。表面看，这是一次救城任务；更大的问题是，三座灯为何会在同一夜被人为关闭。

他最初以为这是一次机关事故。途中救下熟悉驿路的侦察员岚织，并遇到追查军械失控的烬锋。三人逐渐发现，关闭灯阵的人不是要摧毁鸣灯城，而是在寻找被九相神话共同抹去的“第十盏灯”——一座不属于九域、能够改写域与域之间边界的禁灯。

首章回答“谁在关闭北境第一座灯台”，并让玩家第一次看到天穹裂隙与禁灯的影子。章节结尾不解释全部真相，只确认三件事：九域正在互相渗透；灯阵曾经主动抹去一段历史；失联的影刃师父可能仍活着，并站在另一侧。

第一章的神话感不靠堆砌名词，而靠三个逐步升级的画面：山城上空出现第二个月亮；被击败的机关短暂显出古神手印；主灯台点亮时，远处八域同时回应，却有一盏灯从天穹之外亮起。玩家先理解“要送灯”，再意识到自己正在触碰创世秩序。

### 3.2 世界结构与长期伏笔

| 层级 | 设计内容 | 首章只展示 |
| --- | --- | --- |
| 九域 | 每个域有独立生态、机关材料和灯阵传统，关卡视觉与机关来源随域变化 | 鸣灯域的雾山、竹林、驿站与北境旧灯 |
| 天灯阵 | 连接九域的秩序锚，决定航路、季候和灵魂归途 | 失火的灯台、断裂的灯脉、无法解释的雾潮 |
| 天穹裂隙 | 灯阵失衡后产生的空间重叠，带来倒悬地形和异域敌人 | 一次短暂的天空倒影，不作为新玩法教学 |
| 禁灯 | 被抹去的第十盏灯，可能改写域的边界和历史 | 只出现残缺图案与师父留下的半句话 |
| 观灯者 | 维持灯阵的古老组织，可能是守护者，也可能是封锁真相的人 | 敌人徽记和一段被删去的碑文 |

后续章节可以围绕“追查、穿越、选择”推进：玩家不是收集九盏灯来完成简单修复，而是在每个域决定要恢复旧秩序、改变灯阵，还是让两个本不相遇的世界相遇。游戏机制保持跑酷动作核心，宏大叙事通过环境、首领和短对话逐层展开。

### 3.3 神话史诗的冲突轴

| 阵营 / 观念 | 目标 | 不同于简单反派的地方 |
| --- | --- | --- |
| 观灯者 | 维持九域分隔，让天灯阵继续运转 | 他们确实保护了大多数人的生活，但也世代删改历史 |
| 折灯者 | 熄灭旧灯、点燃第十盏灯，让九域重新相连 | 他们相信分隔本身就是神相犯下的错误，愿意承担灾变代价 |
| 三人同行者 | 先救人、再查明真相，最后决定灯阵的未来 | 他们的选择来自具体的人和失去，不代表某个阵营的教条 |

折灯者的首领暂名“无烬王”。他不是单纯追求毁灭，而是认为九域被人为分割后，许多族群、亲人和亡魂永远无法相见。玩家会在不同域看到他的观点有真实依据，也会看到第十盏灯可能带来的代价。最终冲突应是“谁有资格决定世界的边界”，而不是“打倒坏人就恢复原状”。

### 3.4 长篇章节骨架

| 篇章 | 主要舞台 | 神话问题 | 玩法变化方向 |
| --- | --- | --- | --- |
| 第一章·灯火将熄 | 鸣灯域 | 谁关闭了北境天灯 | 学会三名角色与预警机关 |
| 第二章·云门失路 | 云阙域 | 风是否记得所有走过的路 | 高低路线、风场和滑翔节奏 |
| 第三章·赤炉神骸 | 赤炉域 | 古神留下的是武器还是枷锁 | 移动机关、热源节奏、首领护甲变化 |
| 第四章·沉渊回声 | 沉渊域 | 亡魂为何不能归航 | 记忆幻象、可重叠路线、故事选择 |
| 第五章·第十盏灯 | 天穹裂隙 | 世界应恢复边界，还是重新相连 | 汇总已学动作与多阶段终局首领 |

这是叙事远景，不要求首版一次制作五篇。每篇先用一座域、一个首领和一个核心新机关表达神话法则，再将线索推进到下一篇。

### 3.5 三名角色的动机

| 角色 | 身份和动机 | 通过玩法表达 |
| --- | --- | --- |
| 影刃 | 驿路守卫的年轻继任者，要找回失联师父并完成护送 | 三段跳灵活补救，月蚀斩在危险中保护自己 |
| 岚织 | 负责传递灯讯的高崖侦察员，想查明同伴失踪原因 | 滑翔观察落点、跨越较长的空中路线 |
| 烬锋 | 失控机关所属军械所的前护卫，希望阻止自己的装备伤人 | 冲刺穿过攻击间隙，雷击果断、集中 |

名字和人物关系均为暂定。第一章的情绪从“急送灯芯”转向“发现人为破坏”，再落到“三人决定继续同行”。

### 3.6 叙事如何进入游戏

- 关卡开始前：一张场景插图、1～2 句对话，首次展示约 5～8 秒，可立即跳过。
- 跑酷中：优先用断掉的灯路、被封的驿站、异常机关表现故事；安全段最多出现一句非交互台词，不在复杂操作时弹对话框。
- 首领：登场动作和一句台词交代它为什么挡路，战斗开始后交还全部操作。
- 通关后：一句结果、同伴反应和地图上重新点亮的驿灯，约 5 秒。
- 重试默认跳过已看过的剧情，地图详情可重看；暂停不推进对话计时。
- 即使换角色出战，剧情队伍仍是三人同行。头像和台词随说话者显示，不要求“当前操作角色就是每一句话的说话者”。

## 4. 角色与统一身法键

### 4.1 共通底座

三人共用自动跑速、基础二段跳、上下翻绳、自动落绳、基础 3 点生命、武器槽和一个角色忍术。起跳和第二跳参数先沿用当前配置，保持基本操作一致。

每名角色由“基础移动 + 专属身法 + 专属忍术 + 当前武器”组成。旧有被动中的第三跳迁入身法定义；首轮不再额外叠加一个复杂的战斗被动。

核心身法在角色解锁时即完整可用，不通过升级解锁第三跳、滑翔时长或冲刺无敌。初始三人的可通行能力不随成长变化。

### 4.2 统一输入

| 功能 | 键盘建议 | 触屏 | 规则 |
| --- | --- | --- | --- |
| 跳跃 | Space / W / ↑ | 跳跃键 | 所有人最多执行两段基础跳；绳下回上侧 |
| 翻绳 / 快落 | S / ↓ | 翻绳键 | 沿用现有上下与空中快速落绳语义 |
| 身法 | Shift | 原影步位置改为身法键 | 根据角色调用踏影、御风或雷闪 |
| 武器 | J | 武器键 | 仍由装备决定；首轮继续只在首领战启用 |
| 忍术 | K | 忍术键 | 由角色决定，冷却独立 |

右侧跳跃、身法、武器、忍术四个按钮的位置保持一致。身法图标、文字、剩余额度或冷却随角色变化。没有“所有人都能冲刺”的隐藏键盘入口。

影刃的三段跳操作调整为“跳跃 → 跳跃 → 身法”。第三次连续按跳跃不再自动第三跳，避免跳跃键和身法键同时拥有第三跳的两套消费入口。准备页演示与第一次教学必须明确这项变化。

### 4.3 三名角色的身法

| 项目 | 影刃：踏影 | 岚织：御风 | 烬锋：雷闪 |
| --- | --- | --- | --- |
| 操作 | 两段基础跳用完后点按身法 | 空中按住身法，松开结束 | 钢索或空中点按身法 |
| 能力 | 追加一次上升，形成三段跳 | 降低下落速度，延长滞空 | 向前短冲，带短暂保护 |
| 初始参数 | 第三跳初速度沿用 -500 px/s | 下落速度上限 120 px/s；每次离绳累计最多 1.2 秒 | 1000 px/s、0.18 秒；前 0.12 秒保护；6 秒冷却 |
| 使用限制 | 仅空中、二段已用、每次离绳一次 | 仅下降时实际生效，不能悬停或抬升 | 每次按键一次；同次滞空最多一次 |
| 刷新 | 正常落绳或重新抓绳 | 正常落绳或重新抓绳 | 冷却自然恢复；落绳只恢复空中使用资格，不清冷却 |
| 适合 | 高度变化、跳跃补救 | 观察落点、长时间跨过地面危险 | 短窗口、快速穿过单组攻击 |
| 代价 | 需要两次基础跳后判断第三跳时机 | 暴露在空中更久，低顶或空中弹道会限制路线 | 位移不可中途反向；交错机关前需预判落点 |

共同边界：

- 踏影与御风不自带无敌；雷闪不会刷新二段跳、忍术冷却或武器冷却。
- 身法不免除坠落失败，不穿过实体封闭门；雷闪保护期内可以躲过伤害型机关和敌弹，但必须检查完整移动路径，不能在一帧内漏掉碰撞与拾取。
- 御风可松开后再次按住，继续使用本次离绳剩余时长；不因反复按键刷新。空中先按住身法，上升仍按普通轨迹，在转入下降时自动开始消耗。
- 御风不会在按住普通跳跃键时自动发动。影刃在身法尚不可用时点按不排队；有效输入均以按下边沿为准。
- 空中快落立刻结束御风；快落键仍按住时不能再次开始滑翔。雷闪期间接受翻绳或快落意图，优先在本次短冲结束时执行，需试玩确认手感。
- 同帧“第二跳 + 踏影”只执行第二跳，踏影需要新的身法按下事件；同帧跳跃与雷闪可先起跳再短冲，不重复消费跳数。
- 受伤和落绳取消滑翔；暂停冻结时长与冷却、清理按住状态，恢复后需重新按住。死亡、结算和切换关卡清空所有身法状态。
- 第三跳、滑翔都不能在绳下直接发动来绕过“先回上侧”的规则；绳下雷闪保持下侧。HUD 明确显示“先二段跳 / 空中可用 / 下落可用 / 冷却”。

雷闪的冷却与保护明显低于现有共享影步的连续规避能力。移除共享影步后，需要重新回放第一关与首领，不能将旧测试通过等同于新三人已平衡。

### 4.4 忍术与武器

身法负责移动差异，K 忍术负责应急保护和战斗反馈。第一轮保持三人的 K 均为 12 秒冷却、2 秒保护、首领基础总伤害目标 24，先避免同时改变过多平衡变量：

| 角色 | 忍术建议 | 差异 |
| --- | --- | --- |
| 影刃 | 月蚀斩 | 保留当前前方月弧与跑酷清敌范围 |
| 岚织 | 风羽阵 | 六枚基础伤害 4 的羽刃，约 0.6 秒完成发射，实际飞行命中 |
| 烬锋 | 雷裂斩 | 两次基础伤害 12 的雷刃，间隔约 0.2 秒，强调短时爆发 |

前方目标可达性与普通哨兵伤害需单独定义；不能直接把首领伤害 24 用于所有目标。多段攻击按命中时的护甲状态分别结算，不按弹数刷击破或连击。

弦月轮和贯星矛继续通用，保留两把起始武器的已有所有权。首轮不加属性克制、不要求某把武器才能过某关。第三把武器安排在章节循环稳定后，只增加玩法选择。

### 4.5 解锁与角色公平

- 影刃：默认拥有。
- 岚织：1-1 首次通关后救出并免费解锁，接一段可跳过的无失败身法演示，让第二关开始就能选择滑翔。
- 烬锋：1-3 首次通关后加入并免费解锁，接雷闪短教学。
- 解锁不要求三星、不花成长货币，不因花错铜钱卡住角色与剧情。
- 首章任意普通关都要有基础二段跳可走的主路线；专属身法可以让收集或避险更顺手，但不构成角色通行税。
- 三人的高风险路线都可以用不同动作完成；首章不放仅某个角色才能拿到、且影响三星的影晶。

## 5. 第一章结构与难度曲线

章节暂名“灯火将熄”。第一批完成五个节点，而不是同时扩张大量章节。

| 关卡 | 目标时长 | 新内容与学习目标 | 压力设计 | 剧情与解锁 |
| --- | --- | --- | --- | --- |
| 1-1 雾岭断桥 | 约 95～105 秒 | 翻绳、二段跳、身法、固定弹道；保留现有机关鸢小首领 | 疏到密，首领每次只要求识别一种攻击；先复核移除共享影步后的公平性 | 找到第一盏断讯驿灯，救出岚织 |
| 1-2 风雨竹林 | 约 85 秒 | 新落竹预警；把翻绳与落点判断组合 | 两次短高峰，中间喘息，不再增加完整首领 | 发现落竹机关被人为改动 |
| 1-3 残灯驿站 | 约 90 秒 | 已学障碍配合短时开合竹闸；先单独教学再与敌弹组合 | 决策密度增加，不把跑速、弹速同时提高 | 找到军械标记，烬锋加入 |
| 1-4 机关水道 | 约 95 秒 | 已学机关的连续编排与可选空中收集 | 约 12 秒高压 / 5 秒恢复交替，最多两类主威胁叠加 | 运送灯芯进入主灯台下方 |
| 1-5 熄灯台 | 约 115～125 秒 | 约 60 秒路线加正式首领“守灯傀” | 重组已学机制，半血强化每次只增加一个变化 | 点亮首座灯台，确认幕后人为破坏 |

“守灯傀”的具体战斗表另立设计；建议使用上 / 下扫击、预告固定弹道和开放核心的循环。首领战目标 45～55 秒，先以行为压力调难度，再校准生命，不直接给机关鸢翻倍生命。

### 5.1 难度量尺

| 参数 | 1-1 | 1-2 | 1-3～1-4 | 1-5 |
| --- | --- | --- | --- | --- |
| 新机关首次预警 | 至少 1.4 秒 | 至少 1.4 秒 | 至少 1.4 秒 | 至少 1.4 秒 |
| 熟悉机关通常预警 | 约 1.2～1.3 秒 | 至少 1.2 秒 | 1.0～1.2 秒 | 至少 1.0 秒 |
| 相反侧危险之间有效操作时间目标 | 通常 ≥1.2 秒 | 通常 ≥0.95 秒 | 通常 ≥0.85 秒 | 通常 ≥0.80 秒 |
| 同时需要读懂的威胁 | 1，后段短时 2 | 最多 2 | 最多 2 | 可短时 3，均须已学且不要求冲突输入 |
| 恢复段 | 每次教学后都有 | 两个主要高峰之间 6 秒 | 每约 12 秒高压后 5 秒 | 首领前至少 5 秒 |

这些是目标，不直接覆盖现有资源值。连续相反侧危险还要满足当前校验的至少 0.75 秒有效翻绳窗口；目标窗口另加输入锁、身体宽度和设备误差检查。预警时间、危险间距和实际可操作窗口是不同参数，不能混用。

以 320 px/s、相邻宽 54 px 的机关、玩家总宽 36 px 为例，要留 0.95 秒有效空隙，中心距离至少为 `320 × 0.95 + 54 + 36 = 394 px`。不能只以机关中心距离除跑速当作可反应时间。

### 5.2 防止难度失控

- 每关只引入一类主要新机关，用“独立演示 → 简单组合 → 熟练组合 → 恢复”展开。
- 不同威胁必须有相容的安全解；不能要求同一瞬间既在钢索上又在下。
- 一段内优先提高一个维度：操作频率、路线分叉或攻击组合。跑速首章先保持 320 px/s。
- 预警以实际摄像机、可视区域和身法后的接近速度校验。雷闪可能提前到达，不能只按基础跑速估算所有预警。
- 每次受击后保留现有 0.8 秒保护；持续危险按一次接触去重，避免一个碰撞帧连扣数点生命。
- 连续失败三次可提示“练习这一段”，自动读取最近失败点附近的无奖励练习片段。练习进度不带回正式局，不靠付费补给解锁。
- 重试不扣体力、不扣铜钱，基础主线也没有入场券。失败复盘显示段落、受击来源和下一颗星所需改进。

## 6. 第二关：风雨竹林

### 6.1 定位

这关比第一关的跑酷段更强调连续判断，但避免同时加长流程和增加首领消耗。约 85 秒、基础跑速 320 px/s，对应路线目标约 27,200 px。沿用单根水平钢索，第一版不加入真实断绳、风向推力或随机落竹。

唯一主要新机关是“落竹”：在预定钢索侧别出现竹叶抖动、方向轮廓和提示音，随后落下并短暂停留。落点固定，不跟踪玩家。首个演示在抵达前至少 1.4 秒可读，后续至少 1.2 秒；落竹本体建议宽 48 px，危险停留约 0.65 秒，之后退场。所有数值需要按真实角色与可视范围回放。

上侧落竹保留下侧安全线；下侧悬竹保留上侧安全线。第一次只出现上侧落竹，第二次再教学下侧。雨丝和背景竹影不使用预警轮廓或高亮危险色。

### 6.2 节奏表

| 时间 | 段落 | 机关编排 | 压力 1～5 | 普通影晶 |
| --- | --- | --- | ---: | ---: |
| 0～10 秒 | 入林 | 复习上下交替，给选岚织的玩家试身法的安全空间 | 1 | 4 |
| 10～24 秒 | 雨落竹响 | 上侧落竹单独演示、恢复、下侧落竹单独演示 | 2 | 8 |
| 24～38 秒 | 交错竹阵 | 落竹与固定尖刺先后出现，要求落绳后再翻侧；不强制身法 | 3 | 8 |
| 38～44 秒 | 旧驿灯 | 无伤害恢复段，普通影晶成短串，出现一句故事提示 | 1 | 4 |
| 44～62 秒 | 伏弩回廊 | 已学固定弹道与落竹组合；箭隙和安全侧须可同时满足 | 4 | 10 |
| 62～76 秒 | 双径取舍 | 主线简单翻绳；可选空中路线含 6 颗额外影晶，所有角色都能到达 | 3～4 | 10 |
| 76～85 秒 | 竹门追风 | 综合一次落点判断与上下交替；最后 2 秒没有新威胁 | 4 → 1 | 6 |
| 合计 | | | | 50 |

“双径”指在同一钢索附近选择空中轨迹，不新建第二根可走钢索。主路线可收集至少 44 / 50，即 88%；无伤即可三星，额外 6 颗服务全收集挑战。

### 6.3 三种角色如何解决同一段

对一组上侧落竹与后续下侧固定机关：

- 通用解：先下翻通过落竹，再按已预告的空隙回上侧。
- 影刃：二段起跳后踏影补高度，飞过落竹顶部，再快落回到上侧。
- 岚织：二段跳后御风，等落竹退场并选择更靠后的落点；不得用滑翔穿入高处敌弹。
- 烬锋：先确认前方落点，用雷闪缩短在危险区的停留；冲刺结束不能正好撞上下一个反向机关。

这些是路线意图，不能直接作为已经可行的物理结论。灰盒需分别验证二段跳主线及三种专属解；任何专属解不成立时，先修改间距或影晶位置。

### 6.4 验收目标

- 三名角色、两种起始武器、零强化、无消耗品都能通过；主路线无须 K 或身法正好就绪。
- 50 颗普通影晶的摆放不把玩家诱导进必伤位置；主线至少 44 颗、全部 50 颗分别有真实回放。
- 固定落竹与敌弹的组合在暂停、雷闪提前接近、御风延迟落地、重试时不产生无法预警的状态。
- 小范围真人试验目标：熟悉第一关的玩家中，至少 70% 在三次内完成第二关；第一次三星比例目标 10%～25%，五次内至少 40%。样本不足时只作为访谈线索，不宣称概率结论。
- 若失败集中在同一处，先检查预警、视觉遮挡和相冲突的安全解，再调整操作密度；不优先建议玩家买强化。

## 7. 地图、历史成绩与三星

### 7.1 关卡选择界面

第一章使用沿山路向上延伸的驿灯地图：五盏驿灯就是五个关卡节点，通关后灯亮，节点下显示 0～3 颗星。后续章节可以继续延伸，首版不必做一张很长的空地图。

| 区域 | 内容 | 交互 |
| --- | --- | --- |
| 顶部 | 章节名、全章星数 / 15、铜钱余额 | 点击星数查看里程碑，点击铜钱进入商店 |
| 中部 | 五个关卡节点、当前节点、已亮驿灯与短路线 | 点击已解锁节点打开详情；锁定节点显示具体前置关 |
| 底部 | 当前队伍、角色入口、成长、商店 | 配置选择不开始计时 |
| 关卡详情 | 简介、敌情、最高星级、最高分及对应收集 / 受击、最快时间、首次奖励与身法提示 | 开始、练习、重看剧情 |

地图默认定位到最近可推进关，返回时保留滚动位置。三颗星分别点亮的动画很短且可跳过。已领取奖励显示勾，不保留重复红点。

主线按前一关一星通关解锁。章节星数奖励是额外奖励，不以“还差两颗星，禁止继续剧情”制造回刷压力。

### 7.2 分数变成星星

外显主评价改为三星。保留可展开的分数明细和历史最高分，方便用户看到提升；地图优先展示星级。

正式主线成功通关时：

```text
C = 本局普通影晶收集数 / 该关普通影晶总数，取值 0～1
H = 本局有效受击次数
P = 1000 + floor(1000 × C) + max(0, 1000 - 150 × H)

1 星：成功通关，P < 2200
2 星：成功通关，2200 ≤ P < 2600
3 星：成功通关，P ≥ 2600
失败：本次 0 星，不覆盖历史
无伤印：H = 0，独立记录，不影响星级
```

每个正式关都必须配置至少一颗普通影晶。时间、击破数、连击和溢出伤害继续可以显示，但不进入此公式，避免首领血量、敌人数或冲刺速度主导星级。无首领与有首领关的基础分数上限同为 3000。受击会降低分数，但不会把三星硬绑定为无伤：80% 收集、1 次受击时得 2650 分，仍可获得三星；100% 收集、2 次受击时得 2700 分，也仍可获得三星。

实现时用收集数与总数做整数除法 `1000 × collected / total` 并向下取整，避免浮点误差或四舍五入让不足 80% 的收集被计为三星。

| 成功通关表现 | 分数 | 星级 |
| --- | ---: | --- |
| 收集 60%，受击 2 次 | 2300 | 2 |
| 收集 60%，受击 4 次 | 2000 | 1 |
| 收集 80%，受击 1 次 | 2650 | 3 |
| 收集 100%，受击 2 次 | 2700 | 3 |
| 收集 100%，无伤 | 3000 | 3 + 全收集徽记 |

因此三星代表“完成关卡并保持较高收集与较少失误”，不等于无伤挑战。无伤印是独立的精通目标：它可以和 1～3 星中的任意星级同时出现，但正常情况下全收集无伤会同时获得三星。最速放在角色分类的独立纪录中，不额外发成长必需货币。主线没有拖延扣星，但首领本身持续攻击，拖延会增加受击风险。

增加最大生命不会减少 H，护身符挡住的接触也计 H。有效伤害事件需统一去重：同一攻击同一次接触只计一次；本就处于 K / 雷闪 / 受伤保护中的接触不重复计受击，护符在普通伤害本应生效时才触发。无伤印只在 H = 0 时成立，不能用恢复生命或护身符“洗掉”受击。

若一关有 50 颗普通影晶，则 40 颗且 1 次受击为 2650 分，获得三星但没有无伤印。普通影晶总数只计正式可收集对象，装饰光点、剧情灯芯和飞镖球不计入。

### 7.2.1 无伤印展示与奖励

- 结算页在星级下方显示“无伤印”或“本局受击 N 次”；无伤印使用独立图形和音效，不能误读成第四颗星。
- 关卡详情同时保存“最高星级”和“是否获得无伤印”两个字段。全局地图节点可显示小型无伤纹章，点开详情后看到首次取得日期、角色和武器。
- 每关首次取得无伤印奖励 30 铜钱；同一关后续保持无伤只更新纪录，不重复发奖。章节首次集齐 5 枚无伤印，奖励一张外观染色券或章节称号。
- 无伤印不提高角色数值、不解锁必需关卡，也不要求玩家在第一次通关时取得。它服务于愿意精练路线的玩家。
- 护身符挡伤、回春药恢复和增加最大生命都不能取得无伤印；使用补给仍可以正常获得三星和普通通关奖励。
- 结算优先显示“3 星 + 无伤印”或“3 星”，不要只显示一个总分，避免玩家看不出两种目标的差异。

### 7.3 历史纪录边界

- 星级、最高分永远取已完成单局的最好结果，不能把一局的无伤和另一局的收集率拼成三星。
- 最高分保存该局角色、武器、成长、道具、受击、收集、版本与用时快照；最快时间单独保存并标注出战配置。
- 关卡详情默认“全角色最高”，可以切角色查看该角色的纪录；重复奖励仍按关卡发放，不按角色重领首通或星星。
- 练习模式免费，但不发铜钱、不改主线星级；保留练习用时。
- 失败不覆盖既有最高星，主动退出也不补发主线奖励。
- 日常数值调优不随意清空已得星级。结构大改另设关卡修订号，保留旧纪录可查看；同一关的首通和星数奖励不因修订重复发。

### 7.4 结算展示顺序

先展示“通关 / 失败 → 本局星级与历史最高 → 收集和受击明细 → 实际到账奖励 → 下一关 / 重试”。剧情解锁与角色加入随后展示，避免同时播放多个大弹窗。

例：“本次 3 星，历史 3 星；40/50 影晶，受击 1 次。再完成一次无伤通关即可获得无伤印。”若收集也不够，则显示“还需 5 颗影晶，或减少 2 次受击”，不只提示抽象分差。

## 8. 奖励与代币

### 8.1 两种数值各司其职

| 数值 | 来源 | 用途 | 是否消耗 |
| --- | --- | --- | --- |

| 奖励 | 初始建议 | 重复规则 |
| --- | ---: | --- |

| 首次通关额外奖励 | 160 / 关 | 每关一次 |

例：初次 2 星、收集 80%，到账 `60 + 16 + 160 + 80 = 316`。之后同样表现重玩到账 76。由 2 星提升至 3 星、收集 90%，到账 `60 + 18 + 40 = 118`，如触发章节里程碑再单独加。

失败只展示本次练习收获，不支付铜钱；未花钱的直接重试无限次。失败不倒扣已有铜钱；已带入并生效的消耗品按使用规则消耗。这样不会靠“开局拾取、退出”反复领取奖励。

首章所有关的重复奖励先保持相同，避免后关必然成为最高收益刷钱场。正式新关通过首通与新星奖励显著优于原地刷关；熟练后刷简单关仍是允许的选择。

## 9. 局外成长

### 9.1 三条有限成长线

| 项目 | 效果 | 花费 | 开放时间 |
| --- | --- | --- | --- |
| 共修·兵刃 1～3 级 | 全角色 J / K 基础伤害累计 +4% / +8% / +12% | 180 / 360 / 600，逐级支付 | 1-1 通关后开放 1 级，1-3 后开放 2～3 级 |
| 共修·护体 1 级 | 全角色最大生命 3 → 4 | 420 | 1-2 通关后 |
| 秘卷选择 | 解锁两种横向辅助，局前二选一 | 每本 180 | 1-2 通关后 |

兵刃不提升自动飞镖球，避免所有输出渠道一起膨胀。采用稳定的小数伤害累积或等效定点数，不对每枚 2～4 伤害的弹体逐次取整；否则小额强化可能没有效果或因多段攻击异常增幅。

只强化 J / K 时，首领总战斗时长下降通常小于 12%。必须用三角色、两武器、零 / 满强化交叉回放，验证无明显优势武器和阶段跳过。生命强化只增加容错，不改星级中的受击计数。

两本秘卷的初稿：

- **拾光卷**：普通影晶吸取范围 +15%，只对同侧、无遮挡的合法拾取生效，不隔绳、不穿机关吸取。仍需走到对应侧，不能消除路线选择。
- **护行卷**：受击保护从 0.8 秒延长至 1.0 秒，伤害照常结算、H 照常增加。不延长 K 和雷闪的保护。

秘卷只有一个槽，随时在局外免费更换。若吸取范围影响高风险路线边界过大，先撤去拾光卷，使用纯通关收益外的横向辅助重新评估，不能悄悄让某些影晶只有升级后才够得到。

### 9.2 成长如何服务难度

- 首次通关奖励足够买第一档伤害升级；玩家立即感受到局外积累，但不要求购买才能继续。
- 第二关后提供生命或秘卷选择，给不熟练玩家更多容错，也给熟练玩家保留铜钱的理由。
- 第三关后开放后两档小幅伤害升级，帮助缩短已经理解的首领循环。
- 成长上限先锁在伤害 +12%、生命 +1；后续章以新武器、秘卷、角色和外观延展，不自动把所有数值再翻倍。
- 角色切换共享上述成长，不要求重复养三个角色；玩家可以直接体验新身法。
- 界面标“推荐掌握：交错翻绳与落竹预警”，不显示误导性的推荐战力。
- 铜钱花在外观、补给或秘卷上也不形成死档：免费练习和无道具通关始终成立。

## 10. 商店与消耗品

商店设定为“山路行商”，分“共修、秘卷、补给、外观”四页，铜钱余额与预计剩余始终可见。没有随机价格、随机词条或付费刷新，商品效果直接写出。

### 10.1 初始商品

| 商品 | 类型 | 铜钱 | 效果与限制 |
| --- | --- | ---: | --- |
| 兵刃、护体 | 永久成长 | 见上一节 | 显示当前值、升级后值与累计上限 |
| 拾光卷、护行卷 | 永久解锁 | 各 180 | 单秘卷槽，出战前免费切换 |
| 护身符 | 一次性补给 | 40 | 挡住本局第一次本应有效的伤害，避免扣血，仍计一次受击并触发普通受击保护 |
| 回春药 | 一次性补给 | 30 | 生命首次降至 1 且仍存活时恢复 1 点，只触发一次；不能救活致死伤害或坠落 |
| 衣装配色 | 外观 | 600 起 | 不改碰撞、身法与数值；章节完成后开放 |

首版不卖复活、星星、直接通关、额外第三跳或缩短身法冷却。第三把武器可作为后续约 900 铜钱的横向商品，但在完成独立武器设计前不放入实际货架。

### 10.2 出战与重试

- 出战最多选一种消耗品，默认不携带。已购买放在库存中，选择不等于立即消耗。
- 正式开始计时才扣除一件并记入当局快照；未开始的返回、场景加载失败不消耗。带入后即使未触发也消耗，进入前明确写“出战消耗 1 件”。
- 一次通关、失败或主动退出结束这一件的作用，不能跨局留下未触发保护。
- 道具不增加额外战斗按钮。其触发、用尽和剩余状态显示在小图标上。
- 重试默认沿用角色、武器与永久成长，消耗品不自动续带。需要再次带入时在重试界面显式勾选，并显示库存；库存不足时依然可以免费重试。
- 即使使用护身符，也可以获得三星；但护身符挡下伤害后不能获得无伤印。未触发的补给不额外扣星。
- 普通补给仍可正常推进主线、领取首通，不另贴“无效成绩”。练习模式不耗库存，也不发奖励。

### 10.3 经济体验目标

一次普通重复通关约 72～78 铜钱，足以覆盖 30 或 40 铜钱的单件补给后仍有正收益。补给是局部帮助，失败后提示优先引向免费练习，避免每次失败都弹购买窗口。

熟练刷一次应能买一件补给；约 3 次无补给重复通关可买第一档强化；约 8 次可选重复通关可攒一件 600 铜钱外观。首通和新星让推进主线更快。

## 11. 首章收支校核

以下假设五关都成功一次，失败重试不额外产出，初始 120 铜钱；不含未来任务、签到或其他未设计收入。

| 模型玩家 | 每关收集 / 受击 | 每关星数 | 五关通关奖励（含首通与新星） | 章节里程碑 | 总收入（含起始） |
| --- | --- | ---: | ---: | ---: | ---: |
| 求稳 | 60% / 4 次 | 1 | `5 × (60+12+160+40) = 1360` | 0 | 1480 |
| 常规 | 80% / 2 次 | 2 | `5 × (60+16+160+80) = 1580` | 120+200 | 2020 |
| 熟练 | 90% / 0 次 | 3 | `5 × (60+18+160+120) = 1790` | 120+200+300 | 2530 |

常规玩家购买兵刃前两级 540、护体 420、一本秘卷 180，并使用六件 40 铜钱补给共 240 后，剩 640，已经可以买第三档兵刃。求稳玩家用同样的 240 补给预算，买兵刃一级、护体和一本秘卷后剩 460，还可选择兵刃二级。

这是总量校核，不是假设玩家会严格照此购物。还需逐关验证：第一关首次一星即有 `120 + 60 + 12 + 160 + 40 = 392` 铜钱，可买 180 的一级兵刃；第二关解锁生命成长后，是否攒钱由玩家决定，不需要倒刷第一关才能继续。

主要观察指标：

- 首次推进中，是否有人因普通补给反复耗钱而无法买任何永久成长。
- 多数玩家是否在第一章末至少拥有两次可感知的永久成长选择。
- 零强化与满强化的通关率差异是否合理，三星差异是否仍主要来自受击和路线掌握。
- 三名角色的三星率、首领用时、道具依赖和失败段落是否明显偏向一人。
- 铜钱无用途时优先增加外观与横向选择，不用提高主线数值制造被迫消耗。

## 12. 存档、发奖与现有项目迁移

### 12.1 拟新增数据

| 数据 | 建议内容 |
| --- | --- |
| 角色能力 | `mobility_id`、跳跃额度、滑翔参数、雷闪参数；能力效果由已注册实现执行 |
| 关卡目录 | 稳定 `level_id`、章节顺序、前置关、故事 ID、关卡资源、总影晶数、奖励表与修订号 |
| 玩家进度 | 已通关关卡、已解锁角色、剧情已读、章节奖励领取状态 |
| 经济 | 铜钱整数余额、补给库存、已购成长、已解锁秘卷、当前秘卷 |
| 单局成绩 | 原始收集 / 总数、有效受击、计分规则版本、单局分数与星级、出战配置 |
| 发奖账本 | `run_id` 结算结果、首通已领、每关已领星数、里程碑 ID、起始赠送状态 |
| 出战快照 | 角色、武器、成长、秘卷、单件补给及本局已消费标记 |

### 12.2 必须保持的边界

- 买商品要在一次存档事务中同时扣钱与增加所有权 / 库存；不得出现扣钱成功但物品未存。
- 通关发奖、最高星、首通、角色 / 下一关解锁与账本在同一事务提交。结算动画只播放已有结果，不再触发第二次发钱。
- 用稳定的每局 ID 去重；同一 run_id 的暂停、退出或保存重试不能重复发基础通关奖励。每关新星只支付未领取的星数差额。
- 保存失败时保留一次待提交事务，按钮只重试保存，不能重新计算发奖；失败后不叠加新的购买或新一局经济事务，先重试保存或选择明确的仅内存游玩。仅内存状态在界面持续标注，避免误以为已经持久化。
- 道具出战扣除与 run_id 持久化后才开始正式局。异常退出再次打开时不补发奖励、不自动返还已开始局的补给；正常重开免费，始终不续扣下一件。
- 局内配置保持快照，暂停页不能强化、换角色或购买后即时增加血量。
- 仍使用本地临时写入、备份和损坏恢复；不能承诺本地离线档案具有防修改或跨设备实时同步能力。

### 12.3 旧存档

现有 `RunHistory` 保存各关 / 模式的最佳时间、等级和分数，但没有每次最佳的完整受击快照；旧分数公式也与新公式不同。因此不能把旧最高分直接套用 2200 / 2600 阈值，也不能把 S / A / B 武断换成三 / 二 / 一星。

迁移建议：

- 保留现有影刃、两把起始武器、装备、设置及旧纪录，在详情中标“旧版成绩”。
- 旧完整关确有成功通关纪录时，承认第一关已通关、开放第二关与岚织；新星级显示“待重新挑战”，不伪造完整评分。
- 起始赠送只执行一次；旧完整通关可补领一次第一关首通 160，使用与新首通相同的奖励 ID，之后不再重复领首通。基础重复奖励和星级奖励不按旧完成次数追溯发放。
- 跑酷 / 首领练习纪录不用于追溯解锁主线或发首通铜钱。
- 存档格式升级时提供显式迁移；未知字段保留，新版档案仍禁止旧程序覆盖。恢复备份也需保持账本与余额处于同一存档代际。

## 14. 仍需讨论的具体点

1. **故事调性**：已确定为神话史诗。长期主线是九域灯海、天穹裂隙、九相神遗产与第十盏禁灯；第一章仍从护送灯芯、结识同伴、追查熄灯真相切入。
2. **三星严格程度**：已改为综合收集与受击分数，不要求无伤。无伤另以无伤印、首次奖励和章节称号体现。
3. **第三跳操作迁移**：已采用统一身法键；本稿将影刃明确为“两次跳跃加一次身法”，需要在旧玩家回归时做一次提示。
4. **第一章成长节奏**：本稿让常规玩家在章末可接近数值成长上限，后续靠新玩法与外观延展；若希望更长养成，应先增加横向内容，不急于抬高强化上限。

建议下一步确认“无烬王 / 折灯者”的视觉与道德立场，再落地第一章的神话线索灰盒；关卡、经济和正式美术随后用试玩结果逐步校准。
