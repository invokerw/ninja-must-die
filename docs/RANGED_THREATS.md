# 投射物与远程威胁

> 版本：0.3 · 日期：2026-10-24 · 对应游戏设计 v0.8

v0.9 的完整主场景在原 60 秒路线后接入 [小型首领](BOSS_ENCOUNTER.md)，复用此处的画外固定方向平行齐射。本文两次远程遭遇与 60 秒回放指跑酷段；专项终点验证使用 `scenes/practice.tscn`，完整含首领流程由关卡与首领测试共同回放。

## 玩法

远程威胁由固定在屏幕右侧的悬浮发射源产生。默认发射源位于右边缘外，飞弹从画外射入；发射源的位置始终按屏幕计算，不沿钢索摆放，也不会随地图滚到玩家身边。屏内右侧箭头、金色危险路线和 HUD 倒计时提供蓄力预警，飞弹以朱砂尾迹与暖金亮芯显示。

| 参数 | 当前值 |
| --- | ---: |
| 发射源右侧偏移 | 屏幕右边缘外 48 px |
| 发射源高度 | 上侧来袭为屏幕高度 55%，下侧来袭为 80% |
| 发射源接触 / 击破 | 无接触体、不计击破 |
| 蓄力时间 | 0.8 秒 |
| 单次遭遇发射数量 | 1 波、3 枚并排 |
| 相邻弹道中心间距 | 144 px，沿飞行方向的垂线排列 |
| 飞弹方向 | 上侧来袭 `(-1, 0.12)`，下侧来袭 `(-1, -0.04)`，配置后固定 |
| 飞弹速度 | 720 px/s，所有子弹同向同速 |
| 飞弹半径 / 伤害 | 8 px / 1 |
| 回收范围 | 离开屏幕外 96 px；另设足够飞完整屏的寿命兜底，至少 3 秒 |
| 发射恢复反馈 | 0.3 秒 |

关卡进度决定何时开始一次来袭，屏幕决定从哪里发射，关卡配置直接决定方向。发射方向不读取玩家位置、侧别、跑速或预测落点；同波子弹平行飞行，发射后使用世界坐标，不随镜头移动。斜向弹列整体向右平移，确保每枚都从右边缘外入场。1280×720 下，从蓄力到首次接触约 1.7 秒，实际时间随视口、镜头与影步而变化。

平行弹道保留可容纳角色的间隙，翻绳或在合适时机跳入间隙均可躲避。影步无敌、技能无敌与受伤无敌继续各自计时；任一保护有效时，飞弹接触不扣血、不增加受击次数、不中断连击。每枚子弹只结算一次接触，包括被无敌挡住的接触，随后继续飞行，直到离开画面；保护结束后同一颗不会再次扣血。子弹越过玩家也不会提前消失。

发射源没有钢索接触伤害，不属于月蚀斩的击破目标；月蚀斩的无敌可保护玩家通过飞弹。飞弹消失不产生击破或连击奖励，普通哨兵继续使用原有生命与击破规则。

## 关卡与提示

当前 60 秒关卡包含 29 个机关、50 个影晶、5 名钢索普通哨兵和 2 个独立右侧发射源：

| 段落 / 资源 | 玩家触发进度 X | 危险侧 |
| --- | ---: | --- |
| 上下交替 / `Enemy_alternating_1` | 4080 | 下侧 |
| 连续机关 / `Enemy_combinations_2` | 9840 | 上侧 |

入门段继续只教学移动。上下交替段提示“金线预告固定弹道，留意弹道间隙”，每条金线与右侧箭头对应一枚飞弹。HUD 显示“右侧齐射”、弹数与剩余蓄力；相近的同侧机关不会掩盖远程提示。发射后提示“平行飞弹”与“留意间隙”。危险侧仅作为关卡提示元数据，不参与瞄准。

基础二段跳配置、不释放技能的纯翻绳路线仍能无伤收齐所有影晶。三段跳、影步与主动技能提供其他通过方式；主路线不要求冷却就绪。

## 配置与校验

在 `data/levels/fog_ridge_60s.tres` 的段落 `Enemies` 中编辑：

| 字段 | 作用 |
| --- | --- |
| `enemy_type` | `sentry` 为普通哨兵，`shooter` 为独立右侧发射源 |
| `offset_x` | 普通哨兵的放置位置，或右侧来袭开始的玩家进度，均相对段落起点 |
| `cable_side` | 普通哨兵所在侧，或远程遭遇的主要危险侧提示；不影响飞行方向 |
| `health` | 仅普通哨兵使用，发射源不作为可击破目标 |
| `screen_edge_offset` | 相对实际屏幕右边缘；48 为画外，-48 为屏幕右侧内缘 |
| `screen_height_ratio` | 悬浮发射源在屏幕高度中的比例 |
| `windup_seconds` | 完整预警时间，当前 0.8 秒 |
| `projectile_speed` | 飞弹速度大小，当前 720 px/s |
| `fire_direction` | 世界坐标下的固定方向，使用时归一化；负 X 朝左，正 Y 朝下 |
| `volley_count` | 同波并排数量，当前 3，可设 1～7 |
| `volley_spacing` | 沿飞行方向垂线排列的中心间距，当前 144 px |

启动时拒绝未知类型、少于 0.6 秒的预警、低于或等于基础跑速的飞弹速度、超出 -96～128 px 的右侧偏移，以及超出 0.1～0.9 的屏幕高度比例。方向须为有限非零向量且归一化后 X ≤ -0.85；数量须在 1～7 枚之间；多弹的纵向中心间距须至少 112 px，为角色保留间隙。将右侧偏移改为负数，可让发射源在来袭期间显示于画面右边缘内；它仍悬浮在屏幕高度上。

布局校验以 1280×720 和基础跑速逐枚估算与钢索两侧的接触点，检查上下翻绳空间和同侧影晶间隔；发射源的触发点本身不作为钢索危险物。此估算只用于布局检查，不改变实际射击方向。运行时始终使用实际视口与镜头换算发射位置，修改画幅、速度、进度或蓄力后仍需实际回放。

## 实现与生命周期

- `ScreenShooter` 是独立节点，位于 `RangedSources` 屏幕画布中。CanvasLayer 将发射源与世界滚动分离，避免镜头平滑产生位置漂移；发射时将屏幕坐标换算为世界坐标。
- `ScreenShooter` 直接归一化配置方向生成所有子弹的速度，沿其垂线排列出生点。预警线考虑基础镜头滚动以显示画面中的路径；这不影响世界坐标中的固定速度。
- `EnemyProjectile` 使用半径 8 px 的圆形与玩家的实际碰撞形状进行相对运动扫掠，覆盖飞弹高速跨越和玩家单帧越过飞弹。翻绳视为立即换侧，空中移动按连续轨迹检测；`contact_resolved` 防止同一颗反复结算。
- 飞弹共用 `PlayerController.take_damage()`，继承已有无敌、生命、受击与连击规则。当前无需新增玩家碰撞体；首领出现不同受击形状时再评估独立 Hurtbox。
- 飞弹归属于关卡的世界坐标 `Projectiles` 容器，与屏幕发射源分离；命中或越过玩家后继续飞行。飞出屏幕左侧，或向外飞出上下边界 96 px 后回收；寿命按视口和速度预留完整飞行时间，并留额外 1 秒，最低 3 秒。
- 玩家停止信号同步取消蓄力并将飞弹标记失效、隐藏、排队回收；死亡或终点立即暂停场景，也不会留下可继续伤害的飞弹。
- 暂停冻结移动、蓄力、恢复和飞弹寿命；重试重建全部关卡节点和攻击状态，不沿用上一局飞弹。

## 验证

`tests/test_projectiles.gd` 覆盖 960×720、1280×720、1600×900 三种尺寸，镜头滚动与缩放、实时改变视口尺寸、画外 / 右侧内缘位置、真实发射原点、玩家位置与跑速变化时的固定方向、1 / 3 / 5 枚同速平行排列、间隙躲避、命中后完整飞行与单次接触，以及翻绳、跳跃、无敌、高速碰撞、暂停、寿命、HUD、死亡 / 终点清理和重试。成功输出 `PROJECTILES_PASS`。

原有四套回归继续通过：四条完整路线均 0 受击、50 / 50 影晶；两条无技能路线均经历 2 波、共 6 枚飞弹。基础翻绳与冷却技能路线 59.88 秒，跳跃 / 影步路线 59.50 秒。Windows Godot 4.7 图形预览检查三条平行预警、画外齐射入屏、躲避间隙，以及发射源显示在右侧内缘时的悬浮位置。
