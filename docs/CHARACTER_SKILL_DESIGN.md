# 角色主动技能与被动能力设计

> 版本：0.2 · 日期：2026-10-23 · 状态：已实现并通过原型回归
>
> 对应游戏设计文档 v0.7；替代 v0.6 的近身斩击和影能消耗规则。以下数值已作为当前运行配置，后续按手感验收调整。

## 1. 核心规则

每名可玩角色固定拥有 **一个主动技能 + 一个被动能力**。主动技能按键释放，通过时间冷却恢复；被动能力自动生效，不占用额外按键。

- 取消近身普通斩击和 `attack` 输入，移除 `J` 操作提示。
- 取消影能、充能、能量消耗和击破回能。影晶只参与收集、连击和评分，不改变技能冷却。
- 主动技能沿用 `K`，开局和重试时就绪；有效释放后立即进入冷却。
- 每个主动技能都配置一段释放后的无敌时间，从接受释放输入的当帧开始计算。
- 所有角色默认二段跳；只有具备对应被动的角色才增加跳跃段数。
- 上下翻绳、跳跃和 `Shift` 影步继续作为共享移动操作。影步沿用已验收规则，不占角色专属主动技能槽。
- 当前先制作一名角色，完成这一套能力与配置流程；后续角色替换主动和被动资源即可，不同时扩展多名角色或养成系统。

## 2. 第一名角色：影刃

定位是机动与补救：主动技能用于处理前方敌人、保护一段通过路线；被动多给一次空中调整机会。

| 项目 | 设计 |
| --- | --- |
| 角色 ID | `shadow_runner` |
| 主动技能 | 月蚀斩 |
| 被动能力 | 踏影：三段跳 |
| 基础跑速 / 生命 | 320 px/s / 3，保持现有值 |
| 相比基础角色的变化 | 主动技能与额外一次空中跳跃；碰撞体、拾取范围和翻绳身位保持一致 |

### 2.1 主动：月蚀斩

| 参数 | 当前配置 | 规则 |
| --- | ---: | --- |
| 冷却 | 12 秒 | 从成功释放时开始计时 |
| 无敌 | 2 秒 | 从成功释放当帧开始，不等待攻击动画 |
| 出招延迟 | 0.12 秒 | 只作为蓄势反馈，不暂停自动奔跑或移动输入 |
| 伤害 | 3 | 一次释放对每个敌人最多命中一次 |
| 前方范围 | 640 px | 覆盖前方矩形区域，不命中身后敌人 |
| 纵向范围 | 中心上下各 100 px | 附着时以钢索中心为中心，覆盖上下两侧；空中释放以施放者出招时的身体高度为中心 |
| 消耗 | 无 | 不要求收集、命中敌人或达到连击数 |
| 独立释放锁定 | 无 | 移除旧版 0.8 秒锁定，由冷却防止重复释放 |

成功施放后，立即开始冷却和无敌；0.12 秒后按当时角色位置生成一次攻击。附着状态、空中速度和剩余跳跃次数不被技能改变。月蚀斩的伤害不随被动跳跃段数增加。

没有敌人时仍可释放：这是一笔有效的冷却使用，并获得完整无敌，可用于通过危险段。冷却未结束、暂停、死亡或结算状态下的输入无效，不改变任何计时。长按 `K` 不会在冷却结束时自动再次释放，必须重新按键。

以一次施放为例：

| 相对时间 | 攻击 / 操作状态 | 无敌 | 技能剩余冷却 |
| --- | --- | --- | --- |
| 0.00 秒 | 接受输入、播放蓄势反馈，仍可正常操作 | 开始 | 12 秒 |
| 0.12 秒 | 结算一次月蚀斩攻击 | 持续 | 11.88 秒 |
| 2.00 秒 | 技能攻击已结束，继续正常跑酷 | 结束 | 10 秒 |
| 12.00 秒 | 技能再次就绪 | 无 | 0 秒 |

12 秒冷却与 2 秒无敌先作为调试起点：60 秒关卡有多次选择释放的机会；每次保护约 640 px 的基础跑速路程，冷却期间仍需使用翻绳和跳跃。验收后根据实际释放时机、受击位置和通过体验调数值。

### 2.2 无敌的边界

- 无敌期间免疫机关、敌人接触、投射物和首领的伤害；首版不安排穿透主动技能无敌的攻击。
- 免疫的碰撞不扣血、不增加受击次数，也不中断连击。
- 无敌不修正移动轨迹或钢索附着状态；越过坠落失败边界、退出关卡等流程仍正常生效。
- 拾取、终点和分段触发保持有效，不能通过关闭玩家整个碰撞体实现无敌。
- 技能无敌、受伤无敌和影步无敌分别计时。只要任一保护仍有效，就不能受伤；时长不相加，较短的保护不能覆盖较长的保护。
- 同一物理帧中，先接受有效技能输入并建立无敌，再结算该帧接触伤害，避免“已经按出技能却先扣血”。
- 无敌结束前 0.35 秒显示逐渐收拢的光圈，结束时恢复正常轮廓；此后仍与机关重叠会按正常规则受伤。

### 2.3 被动：踏影（三段跳）

这里的“三段”包含从钢索上起跳的第一段：**一段起跳 + 两次空中追加跳跃**。

| 状态 | 所有角色的基础规则 | 影刃装备踏影后 |
| --- | --- | --- |
| 钢索上按跳跃 | 一段起跳 | 一段起跳 |
| 空中再次按跳跃 | 二段跳 | 二段跳 |
| 空中第三次按跳跃 | 不再追加跳跃 | 三段跳 |
| 空中第四次按跳跃 | 不再追加跳跃 | 不再追加跳跃 |
| 钢索下按跳跃 | 只翻回上方 | 只翻回上方 |
| 落绳或成功重新抓绳 | 恢复基础跳跃次数 | 恢复三段跳次数 |

第一段与第二段沿用当前初速度 -680 / -548 px/s，第三段先用 -500 px/s，重力保持 1800 px/s²。第三段主要增加调整与滞空机会，不提高第一、第二段的起跳强度。

跳跃计数遵守以下规则：

1. 基础最大跳跃段数为 2，踏影只额外增加 1 次空中跳跃，不直接修改所有角色的全局参数。
2. 在钢索下翻回上方不消耗第一段，也不额外起跳；要再次按跳跃才离开钢索。
3. 只有实际落绳或成功手动抓绳才刷新空中额度。技能、影步、受击、收集物、碰撞钢索侧面和上升穿绳均不刷新。
4. 下落接近钢索时，手动抓绳沿用优先规则；抓绳成功会消耗这次按键，不能立即把同一输入继续用于起跳。
5. 每次追加跳跃都需要新的按键边沿。长按跳跃、落绳时的旧缓冲输入不能自动连续跳跃。
6. 在空中释放技能不中断当前跳跃、不重置垂直速度、不赠送空中跳跃次数。第三段后释放技能也不能再跳第四段。

## 3. 影晶、敌人与关卡

影晶保留已有的收集计数、每个 20 分和连击事件。击破敌人保留每个 150 分和连击事件，移除“+20 影能”。评级继续采用用时、受击与收集率；不增加“必须释放多少次技能”的门槛。

没有近身斩击后，普通敌人的选择是“翻绳 / 跳跃躲避、影步通过，或使用主动技能击破”。机关不会被月蚀斩清除，无敌有效时可以安全接触通过，保护结束后机关仍保留正常判定。

当前关卡包含 29 个机关、50 个影晶、5 个普通哨兵与 2 次屏幕右侧远程遭遇。普通哨兵可被月蚀斩击破；右侧发射源不占钢索位置、不作为击破目标，使用技能无敌可应对飞弹。路线必须满足：

- 使用基础二段跳配置、不释放主动技能，也能完成主路线并无伤收齐影晶。
- 三段跳只提供可选路线与失误补救，主路线不能依赖第三段跳。
- 不安排“技能未冷却好就必定受伤”的连续关卡门槛，不要求玩家按固定秒表释放。
- 影晶继续位于钢索附着身体范围内；不因加入三段跳而抬高或下移普通影晶。
- 第一处哨兵保留足够可见预警与翻绳空间；教学提示改为“翻绳避开；K 释放角色技能”。
- 教学第二段展示技能与无敌，组合段说明冷却和三段跳，收尾段让玩家自行决定保留还是释放技能。

技能不再短暂停顿，因此下一轮不沿用旧版技能回放的 60.35 秒作为验收时长；重新验证约 60 秒路线、命中次数、受击与收集结果。

## 4. HUD、角色说明与反馈

技能区域改为一个主动按钮，显示当前角色的技能名称、`K` 和就绪状态；冷却时覆盖灰色进度与剩余秒数，最后 2 秒显示到 0.1 秒。就绪时一次柔和高亮，不反复闪烁。移除影能条、“充能”“影能不足”和 `J 斩击` 提示。

角色信息显示“影刃 · 主动：月蚀斩 · 被动：踏影（三段跳）”。钢索附着时显示被动名称；空中可显示剩余追加跳跃次数，起跳后为 2、二段跳后为 1、三段跳后为 0。被动没有按钮和冷却。

能力信息与冷却按钮收在屏幕边缘，移除旧充能条后不保留横跨画面的战斗文字栏。三段跳最高点也必须能看清角色，不被 HUD 遮挡，相机不能因第三段跳产生突然拉动。

无敌用角色月光描边、环绕金色光圈和剩余时长表示，与受伤后的透明闪烁区分；攻击命中特效和保护光圈分开播放，避免把 2 秒无敌误认为持续 2 秒伤害。

后续角色选择页展示一个主动、一个被动、技能冷却与无敌时长。角色在开局前确定，本局中不能切换以刷新冷却；当前首版只有影刃，不先制作完整选角界面。

新增人物与技能图片继续使用统一 imagegen 风格锚点；布局、数字、冷却进度和剩余跳数由 Godot 动态渲染。当前使用已验收原型的代码占位视觉；本轮仅调整动态 HUD 与保护光圈，正式图片仍按 `art/README.md` 的生成流程交付。

## 5. 数据与实现边界

以下结构已实现，主场景的 Player 引用 `data/characters/shadow_runner.tres`：

| 数据 / 模块 | 职责 |
| --- | --- |
| `CharacterData` | 角色 ID、名称、描述，以及恰好一个主动资源和一个被动资源 |
| `ActiveSkillData` | 技能 ID、名称、冷却、无敌时长、出招延迟、攻击范围和伤害 |
| `PassiveData` | 被动 ID、名称、类型与参数；踏影的参数为额外空中跳跃 +1 |
| `PlayerTuning` | 共享移动参数与基础最大跳跃段数 2；移除普通斩击、影能及旧技能锁定参数 |
| `PlayerController` | 钢索移动、有效跳跃额度与无敌伤害入口 |
| `RunnerCombat` | 角色主动技能的施放、冷却、命中记录及连击 / 击破统计；删除普通攻击和能量分支 |
| `RunResult` | 保留现有评分，技能冷却与被动能力不直接加分 |

影刃的实际配置：

```text
character_id: shadow_runner
active_skill:
  skill_id: moon_slash
  cooldown_seconds: 12.0
  invulnerability_seconds: 2.0
  cast_delay_seconds: 0.12
  forward_range: 640.0
  half_height: 100.0
  damage: 3
passive:
  passive_id: triple_jump
  extra_air_jumps: 1
shared_base_jump_count: 2
```

配置在开局校验：角色必须有主动和被动，冷却必须大于无敌时间，延迟必须小于无敌时间，伤害和范围须为正。首版有效跳跃段数只允许 2 或 3。配置资源只读，冷却、无敌和跳跃额度保存在本局实例中。

冷却与无敌使用游戏时间，暂停时都停止推进。死亡、结算不再施放技能；重试重建本局状态，冷却恢复就绪，跳跃额度按角色重新计算。进入终点时取消未结算的技能攻击，避免在成绩锁定后增加击破数。

## 7. 已完成验收清单

- `J` 不触发近身攻击，画面中没有影能条，拾取和击破不改变冷却。
- 开局就绪；空放有效；成功释放一次只启动一次冷却；冷却中、长按和无效状态不会重复施放。
- 主动技能从输入接受时起保护 2 秒，包括同帧接触；超过保护时长才恢复受伤，且不会提前覆盖其他更长保护。
- 技能在钢索上、钢索下和空中都可释放，不打断移动、不刷新跳跃额度、不关闭拾取和终点判定。
- 基础二段跳配置最多一段起跳 + 一次空中跳；踏影最多一段起跳 + 两次空中跳，第四次按键无效。
- 钢索下按跳跃只上翻；下键连按 / 长按仍稳定挂绳；手动抓绳、自动落绳和长按跳跃不产生额外起跳。
- 三段跳在最高点仍有清晰剪影，HUD 不遮挡角色；新增额度不改变原有二段跳轨迹和钢索下影晶的可达性。
- 暂停冻结冷却和无敌，重试清除旧计时，死亡 / 结算后不再补结算技能伤害或改变成绩。
- 用基础二段跳配置验证无技能通关和全收集，再验证三段跳补救与冷却技能路线；不以旧版斩击 / 回能测试的通过替代新机制验收。

## 8. 实现与验证记录（2026-10-23）

- `PlayerController` 以物理优先级 -100 先更新独立保护计时，再通知 `RunnerCombat` 接受技能输入，随后处理移动；机关与哨兵在后续物理回调结算接触伤害。同帧技能输入的无敌已用真实重叠碰撞验证。
- `physics_tick` 仅在角色有效且游戏未暂停时推进；停止信号同步清除待出招攻击，终点先停止角色再锁定评分。
- `tests/test_combat.gd` 覆盖配置校验、空放、12 秒冷却 / 长按、2 秒保护边界、同帧接触、独立保护、前摇中翻绳 / 起跳 / 空中跳 / 影步、钢索中心与空中攻击中心、3 点单次伤害、二段 / 三段跳、拾取 / 终点、暂停、死亡 / 坠落取消。当前 v0.8 回归使用 5 处普通哨兵；屏幕外发射与飞弹保护另由 `tests/test_projectiles.gd` 验证。
- `tests/test_rope_landing.gd` 保留基础二段跳配置的 8 项钢索回归；`tests/test_rope_pickups.gd` 验证 26 个上侧、24 个下侧影晶的正确 / 相反侧拾取。
- `tests/test_level_route.gd` 的四条路线均为 0 受击、50 / 50 影晶：基础纯翻绳 59.88 秒，基础二段跳 / 影步 59.50 秒，冷却技能 59.88 秒，三段跳 / 快速落绳 / 影步 / 技能 59.50 秒。后两条各击破 3 个哨兵；不依赖击破数取得 S。
- 已启动 Godot 图形预览检查就绪、空中技能及三段跳高点，角色剪影未被 HUD 遮挡，相机保持垂直稳定。动态信息沿用墨夜、月光与暖金色板，正式图片仍待生成并导入。

调整角色时，在 Godot 检查器打开 `res://data/characters/shadow_runner.tres`，展开 `Active Skill` 和 `Passive`。共享二段跳基础、三段初速度仍在 `res://data/control_tuning.tres`。目前只实现月蚀斩与增加空中跳跃的效果；新增不同技能行为需扩展脚本，不能仅改 ID。
