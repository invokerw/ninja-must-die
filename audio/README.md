# 原型音效

21 个短音效由 `tools/generate_sfx.py` 使用 Python 标准库合成。素材来自正弦波、频率滑动和带固定种子的滤波噪声，没有采样外部音频。此处不包含背景音乐、配音或正式拟音。

格式为 22,050 Hz、16 位、单声道 WAV，总计约 311 KiB；导入配置保留 PCM。单段长 0.10～0.85 秒，首尾包络回到零，原始峰值限制为满幅的 65%，运行时再降低播放音量。

| 文件 | 用途 |
| --- | --- |
| `jump` / `air_jump` / `land` / `flip` / `dash` | 起跳、空中追加跳跃、落绳、翻绳、影步 |
| `pickup` | 影晶 |
| `skill` / `strike` / `ready` | 技能施放、斩击、冷却结束 |
| `hit` / `guard` / `kill` | 受击、保护 / 护甲接触、普通击破；弱点命中复用 `hit` 的声音 |
| `warning_top` / `warning_bottom` / `volley` | 上侧高音预警、下侧低音预警、整波齐射发射 |
| `boss_enter` / `sweep` / `weakpoint` / `boss_kill` | 首领登场、横扫、弱点开放、击破 |
| `clear` / `fail` | 完成与失败 |

在项目根目录运行 `python tools/generate_sfx.py` 可重建 WAV；然后使用 Godot 导入。调整音色时编辑生成器中的频率、延迟、噪声与时长，调整混音时编辑 `RunFeedback` 的音量与事件优先级。

局内使用固定 8 声部池，并对重复事件限频；危险预警、受击和首领关键事件可替换低优先级声音。结算单独使用 1 个声部，不受场景暂停影响。无显示的高速测试加载并验证音频资源及事件，但不启动输出混音；实际声音播放由图形模式的 `tests/test_feedback.gd` 验证。
