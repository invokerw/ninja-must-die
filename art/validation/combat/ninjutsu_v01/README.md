## 自动行为

`test_combat.gd` 在现有场景 / 玩家夹具中验证：

- 未知技能 / 模式、非法段数、非有限间隔 / 弹速、出手超过保护期拒绝。
- 12 秒冷却 / 当帧 2 秒保护不变；风羽阵首枚出手后目标未立即受伤，六次实际飞行命中；雷裂斩第一刃与第二刃分时结算。
- 普通目标每段伤害、身后目标不受伤、不按弹数产生击破或连击。
- 首次命中使用弱点倍率，之后切换护甲，剩余各段按命中时状态结算；技能伤害统计正确。
- 暂停冻结队列和冷却；停止、死亡、首领击破取消剩余序列与飞行弹体；首领只计一次击破。
- 60000 px/s 单帧跨越的羽刃仍准确命中一次；静态资源不被运行时修改。

`test_weapons.gd` 在原角色切换 / 重试流程补飞行羽刃与技能队列清空；`test_ui_components.gd` 检查实际 HUD 和暂停跟随风羽阵名称 / 说明。

本地串行完整 19 套 GDScript、跨进程隔离档案写入 / 读取和 5 项 Python 导出检查均通过（退出 0、相应 PASS、无脚本错误）。[最终清单 / 日志](validation.json)已保存。导入仍有既有 EditorSettings 退出设置错误，未记为无错误导入通过；后续运行时日志无此错误。
