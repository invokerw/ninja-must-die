# 影刃疾行

Godot 4.7 钢索跑酷原型。当前版本 v0.14 提供约 100 秒的“雾岭断桥”完整流程：60 秒跑酷路线后进入带半血强化的小型首领战，包含键盘 / 多指触屏操作、上下翻绳、跳跃、影步、机关预警、影晶、普通哨兵、屏幕右侧远程威胁、角色技能与被动、可更换武器、飞镖球、音效、粒子、连击、结算、历史纪录与重试。

首名角色“影刃”：主动 **月蚀斩**，12 秒冷却、2 秒无敌；被动 **踏影**，从基础二段跳提升到三段跳。已移除近身普通斩击和影能。详细规则见 [角色技能设计](docs/CHARACTER_SKILL_DESIGN.md)。

## 运行

使用 Godot 打开 `project.godot`，按 F5 进入“角色与武器”准备页。此项目使用 GDScript，不需要 .NET 编译。

Windows 本机已检测到 Godot：

```powershell
$godotPath = 'D:\Godot_v4.7\Godot_v4.7-stable_mono_win64_console.exe'
& $godotPath --path .
```

准备页可预览并装备弦月轮 / 贯星矛，选择自动保存；三种模式入口下显示各自历史最佳纪录，再进入完整关卡、首领练习或跑酷练习。打开 `scenes/main.tscn` 按 F6 可直接运行完整关卡。打开 `scenes/boss_practice.tscn` 按 F6 可直接练习首领；`scenes/practice.tscn` 保留原有 60 秒跑酷练习。命令行也可指定场景：

```powershell
& $godotPath --path . res://scenes/boss_practice.tscn
```

macOS 可使用以下路径（下文原有测试命令沿用此写法）：

```sh
/Applications/Godot_mono.app/Contents/MacOS/Godot --path .
```

Android / Windows 自动打包已配置为推送 tag、发布 Release 或手动运行触发。tag 产物在 Actions artifact 下载，Release 产物自动附加到该 Release；Android 未配置签名密钥时输出调试 APK，配置三项 Secrets 后输出正式签名 APK。使用步骤见 [打包与发布](docs/BUILD_RELEASE.md)。

## 操作

- `Space` / `W` / `↑`：钢索下翻回上方；钢索上跳离钢索；空中追加跳跃（影刃最多三段）或重新抓绳
- `S` / `↓`：钢索上翻到下方；已经在钢索下时保持附着，连按或长按都不会松绳
- `Shift`：影步
- `J`：已装备武器技能，仅首领正式交战时启用；弦月轮 6 秒冷却，贯星矛 8 秒冷却
- `C` / “角色与武器”：暂停并查看本局角色与装备；返回准备页后可更换
- `K`：月蚀斩，开局就绪，冷却 12 秒；按下立即无敌 2 秒，0.12 秒后攻击前方
- `Esc`：暂停/继续
- `R` / `Enter`：使用本局相同装备重新开始
- `F2` / 右上角“设置”：打开体验反馈设置，独立开关音效、粒子、画面震动和冲击闪光
- `M`：静音 / 恢复音效；暂停与结算时也可操作

单跳、二段跳和三段跳下落时会自动落回钢索，无需再次按键抓绳。下键只负责切到钢索下方，重复按下不会脱离钢索；按 `Space` / `W` / `↑` 可翻回上方。

普通影晶位于钢索上下两侧的角色身位内，翻到对应一侧后保持附着即可收集。

后 3 段出现朱砂翼形哨兵。可翻到另一侧安全通过，或按 `K` 释放月蚀斩。技能不打断奔跑、翻绳、跳跃与影步，向前 640 px 造成 3 点伤害；挂绳时覆盖上下两侧，空中以出招时身体高度为中心。空放也进入冷却并提供完整保护，长按不会自动重放。

另有两次**屏幕右侧远程来袭**：发射器固定在右边缘外 48 px、悬浮于屏幕高度的 55% / 80%，位置跟随屏幕，不占钢索上的敌人位置。屏内箭头、平行金线和 HUD 先预警 0.8 秒，随后每波 3 枚飞弹从画外以 720 px/s 并排射入。方向由关卡预先配置，始终保持一致，不按玩家位置瞄准；相邻弹道中心间距 144 px，可翻绳或跳进间隙。子弹经过玩家后继续飞出画面，每枚只结算一次接触，影步或技能无敌可保护通过。发射源不参与接触伤害与击破计分。详见 [投射物与远程威胁](docs/RANGED_THREATS.md)。

原路线末端的朱砂门通向首领 **断桥机关鸢**。它按“上侧横扫 → 下侧横扫 → 三重平射”循环，每次预警 1.2 秒；上侧横扫下翻，下侧横扫上翻，平射从屏幕右侧外沿固定方向并排射入，钢索上侧留有间隙。收招后核心变金、弱点开放 2.6 秒。首领有 180 点生命，护甲期间受到 50% 伤害、弱点期间受到完整伤害；月蚀斩对首领基础伤害为 24，仍保留 12 秒冷却与 2 秒无敌。

首领战中 `J` 释放当前武器：弦月轮即时连发三枚刃波，每枚基础伤害 4；贯星矛蓄势 0.30 秒后发出一枚长矛，基础伤害 16。两者没有无敌，冷却独立于 K。每次首领攻击在安全侧生成一个三刃形飞镖球，拾取后自动连续发出三枚飞镖，每枚基础伤害 2；漏球不影响继续战斗。所有友方弹体实际飞行、有限转向并碰撞首领，按命中时的状态结算，不增加影晶或逐弹刷连击。击破首领后结算，普通哨兵击破为可选收益。详见 [小型首领](docs/BOSS_ENCOUNTER.md)。

影刃的一段起跳后还能追加两次空中跳，第四次按键无效。钢索下按跳跃只上翻，不消耗跳数；落绳 / 抓绳恢复额度，技能与影步不恢复。空中按下键可快速落绳。

保护期间仍可收集影晶和进入终点；尖刺不会被清除，坠落失败边界仍有效。技能、受伤和影步的保护各自计时，互不相加或覆盖。

收集影晶或击破敌人增加连击；2 秒内没有新事件或受到伤害时中断，最高连击保留到结算。

跳跃、翻绳、影步、拾取、技能和战斗均有短音效与碎屑反馈；上侧预警使用高音、下侧预警使用低音，首领弱点开放与技能重新就绪各有提示。受击与首领击破附带轻微震动和冲击闪光。震动只处理最终画面，HUD 保持稳定，镜头、碰撞体和固定弹道不受影响。准备页、局内、暂停与结算的反馈设置使用同一套开关；每次调整自动保存，重启后恢复。装备、成绩与反馈偏好共同保存至 `user://save.json`。详见 [音效与反馈](docs/FEEDBACK.md)。

移动端自动显示左侧独立跳跃键和翻绳键、右侧影步 / 武器 / 忍术和顶部暂停按钮，支持多指同时操作。跳跃键在钢索上侧起跳、空中追加跳跃，下侧置灰禁用，需先翻回上侧；翻绳键在上侧下翻、下侧上翻，空中点按立即快速落绳，长按只执行一次。按钮名称与冷却跟随实际状态。桌面按 `F3` 可切换触屏预览并用鼠标点按；也可使用 `-- --touch-controls` 启动。准备页、设置、详情、暂停、重试与返回均可触摸操作。原型与桌面模拟验证已完成，Android 实机仍待验收。详见 [移动端触屏操作](docs/TOUCH_CONTROLS.md)。

## 成绩与存档

成功完成一次模式后，自动记录最快时间、最高评级、最高分、最佳收集和完成次数；各项最佳独立更新。完整关卡、跑酷练习和首领练习分别保存，失败、中途重试或返回准备不生成通关纪录。首领练习在准备页只显示最快时间与完成次数，不参与整关评级。

保存失败时，本次成绩和设置仍在内存有效，准备页、设置面板与结算页提供“重试保存”。写入使用临时文件替换并保留上一份有效备份；主文件损坏或缺失时尝试恢复备份，均不可用时回退默认配置。旧版装备存档兼容，未知字段保留，较新版本不覆盖。详细规则见 [成绩、设置与存档](docs/SAVE_SYSTEM.md)。

## 关卡编排

路线由 `data/levels/fog_ridge_60s.tres` 配置，在 Godot 检查器中可编辑段落、提示、机关和影晶。

| 基础跑速时间 | 段落 | 内容 |
| --- | --- | --- |
| 0～10 秒 | 钢索入门 | 稀疏机关、上下翻绳与影晶引导 |
| 10～25 秒 | 上下交替 | 交替侧别，建立稳定节奏 |
| 25～45 秒 | 连续机关 | 同侧机关组合，可选跳跃跨越 |
| 45～60 秒 | 冲刺收尾 | 缩短机关间距，可选影步加速，末段奖励 |
| 约 60～100 秒 | 首领追逐 | 上下横扫、平行齐射、飞镖球、武器与角色技能、击破结算 |

跑酷段总计 29 个机关、50 个影晶、5 个钢索接触哨兵和 2 次屏幕右侧远程遭遇。下侧来袭在上下交替段触发，上侧来袭在连续机关段触发。跑酷段纯翻绳可无伤收齐；首领段结合飞镖球、J 武器与 K 月蚀斩击破。影晶高度绑定身位，数据检查覆盖机关、敌人、预计飞弹遭遇点之间的翻绳空间及同侧影晶间隔。详细编辑方法见 [关卡编辑说明](data/levels/README.md)。

## 当前范围

已完成控制、60 秒跑酷、基础战斗、投射物与远程威胁、小型首领、首轮音效 / 粒子 / 冲击反馈，以及角色准备页、两把可更换武器、装备持久化和三渠道首领战斗。21 个合成音效由仓库脚本生成，来源与重建方法见 [音效说明](audio/README.md)。当前地图、首领与粒子使用代码绘制的占位视觉；尚未加入正式图片，提示词和状态见 `art/`。武器归角色模块，准备页更换并保存每名角色的装备，局内与暂停时只读；重试沿用本局配置快照，返回准备后可换装。详见 [首领战斗扩展](docs/BOSS_COMBAT_DESIGN.md) 与 [角色模块及可更换武器](docs/CHARACTER_WEAPON_DESIGN.md)。v0.12 已补齐成绩与四个反馈开关的持久化、准备页历史纪录、备份恢复与保存失败重试。v0.13 增加半血强化：生命 ≤50% 时标记强化，后续齐射改为每波完整预警的双波，保留当前招式与 2.6 秒弱点；血条、外环、音效和粒子提示强化。v0.14 已实现多指触屏按钮、冷却反馈、安全区与可触摸的设置 / 暂停 / 重试全流程。后续包括正式美术、Android 实机验收和性能验证。

HUD 增加动态武器图标 / 名称 / J 冷却与角色详情入口，结算增加三种输出的伤害统计。HUD 显示当前段落、侧别预警、角色被动、剩余空中跳跃、技能就绪 / 冷却、无敌剩余时间、击破和连击；首领战增加生命条、动作倒计时和弱点提示。角色配置在 `data/characters/shadow_runner.tres`，共享移动参数在 `data/control_tuning.tres`。结算保留用时、受击、收集率、击破、最高连击、总分和评级。完整关卡以 100 秒、跑酷练习以 60 秒为评级基准：S 为 +1 秒内、无伤、收集率 ≥90%；A 为 +10 秒内、受击 ≤1 次、收集率 ≥65%；B 为 +25 秒内、受击 ≤2 次、收集率 ≥35%；其余为 C。普通哨兵击破不是取得 S 的必要条件；首领练习只显示练习结果。

总分 = 通关 1000 + 时间奖励（最高 1000）+ 无伤奖励 500 + 影晶数 ×20 + 击破数 ×150 + 最高连击 ×10。时间奖励按基础时长 / 实际用时递减，最多 1000。
