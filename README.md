## 运行

使用 Godot 打开 `project.godot`，按 F5 进入“角色与武器”准备页。此项目使用 GDScript，不需要 .NET 编译。

Windows 本机已检测到 Godot：

```powershell
$godotPath = 'D:\Godot_v4.7\Godot_v4.7-stable_mono_win64_console.exe'
& $godotPath --path .
```

准备页可预览并装备弦月轮 / 贯星矛，选择自动保存；三种模式入口下显示各自历史最佳纪录，再进入完整关卡、首领练习或跑酷练习。打开 `scenes/main.tscn` 按 F6 可直接运行完整关卡。打开 `scenes/boss_practice.tscn` 按 F6 可直接练习首领；`scenes/practice.tscn` 保留原有 60 秒跑酷练习。命令行也可指定场景：

```powershell
& $godotPath --path . res://scenes/boss_practice.tscn
```

macOS 可使用以下路径（下文原有测试命令沿用此写法）：

```sh
/Applications/Godot_mono.app/Contents/MacOS/Godot --path .
```

Android / Windows 自动打包已配置为推送 tag、发布 Release 或手动运行触发。tag 产物在 Actions artifact 下载，Release 产物自动附加到该 Release；Android 未配置签名密钥时输出调试 APK，配置三项 Secrets 后输出正式签名 APK。使用步骤见 [打包与发布](docs/BUILD_RELEASE.md)。


角色灰盒统一使用 `tools/run_sandbox.gd`，无需为每个角色创建场景，且临时档案与正式存档隔离：

```sh
/Applications/Godot_mono.app/Contents/MacOS/Godot --path . --script res://tools/run_sandbox.gd -- --character=wind_scout --mode=parkour --touch
```

将角色改为 `thunder_guard` 可测试烬锋，模式可选 `parkour` / `boss` / `full`。两名灰盒角色仍使用占位着色和共用月蚀斩逻辑，第一关通关已记录岚织所有权，正式角色选择与专属忍术尚未接入。场景保留条件和验收后清理流程见 [测试场景规范](docs/TEST_SCENES.md)。

## 操作

- `Space` / `W` / `↑`：钢索下翻回上方；钢索上跳离钢索；空中执行第二段跳跃或重新抓绳
- `S` / `↓`：钢索上翻到下方；已经在钢索下时保持附着，连按或长按都不会松绳
- `Shift`：角色身法；影刃在二段跳后点按踏影，岚织下降时按住御风，烬锋点按雷闪
- `J`：已装备武器技能，仅首领正式交战时启用；弦月轮 6 秒冷却，贯星矛 8 秒冷却
- `K`：月蚀斩，开局就绪，冷却 12 秒；按下立即无敌 2 秒，0.12 秒后攻击前方
- `Esc`：暂停/继续，并在暂停界面查看本局技能与武器说明
- `R` / `Enter`：使用本局相同装备重新开始
- `F2` / 暂停界面“设置”：打开体验反馈设置，独立开关音效、粒子、画面震动和冲击闪光
- `M`：静音 / 恢复音效；暂停与结算时也可操作

单跳、二段跳和三段跳下落时会自动落回钢索，无需再次按键抓绳。下键只负责切到钢索下方，重复按下不会脱离钢索；按 `Space` / `W` / `↑` 可翻回上方。

普通影晶位于钢索上下两侧的角色身位内，翻到对应一侧后保持附着即可收集。

后 3 段出现朱砂翼形哨兵。可翻到另一侧安全通过，或按 `K` 释放月蚀斩。技能不打断奔跑、翻绳、跳跃与身法，向前 640 px 造成 3 点伤害；挂绳时覆盖上下两侧，空中以出招时身体高度为中心。空放也进入冷却并提供完整保护，长按不会自动重放。

另有两次**屏幕右侧远程来袭**：发射器固定在右边缘外 48 px、悬浮于屏幕高度的 55% / 80%，位置跟随屏幕，不占钢索上的敌人位置。屏内箭头、平行金线和 HUD 先预警 0.8 秒，随后每波 3 枚飞弹从画外以 720 px/s 并排射入。方向由关卡预先配置，始终保持一致，不按玩家位置瞄准；相邻弹道中心间距 144 px，可翻绳或跳进间隙。子弹经过玩家后继续飞出画面，每枚只结算一次接触，雷闪的短时保护或忍术无敌可保护通过。发射源不参与接触伤害与击破计分。详见 [投射物与远程威胁](docs/RANGED_THREATS.md)。

原路线末端的朱砂门通向首领 **断桥机关鸢**。它按“上侧横扫 → 下侧横扫 → 三重平射”循环，每次预警 1.2 秒；上侧横扫下翻，下侧横扫上翻，平射从屏幕右侧外沿固定方向并排射入，钢索上侧留有间隙。收招后核心变金、弱点开放 2.6 秒。首领有 180 点生命，护甲期间受到 50% 伤害、弱点期间受到完整伤害；月蚀斩对首领基础伤害为 24，仍保留 12 秒冷却与 2 秒无敌。

首领战中 `J` 释放当前武器：弦月轮即时连发三枚刃波，每枚基础伤害 4；贯星矛蓄势 0.30 秒后发出一枚长矛，基础伤害 16。两者没有无敌，冷却独立于 K。每次首领攻击在安全侧生成一个三刃形飞镖球，拾取后自动连续发出三枚飞镖，每枚基础伤害 2；漏球不影响继续战斗。所有友方弹体实际飞行、有限转向并碰撞首领，按命中时的状态结算，不增加影晶或逐弹刷连击。击破首领后结算，普通哨兵击破为可选收益。详见 [小型首领](docs/BOSS_ENCOUNTER.md)。

所有角色一段起跳后只能用跳跃键追加一次二段跳；影刃还可点按身法发动第三跳，第三次按跳跃无效。钢索下按跳跃只上翻，不消耗跳数；落绳 / 抓绳恢复跳跃和空中身法额度，雷闪冷却保留，忍术与拾取不刷新额度。岚织御风累计最多 1.2 秒，松开暂停消耗，快落或受伤取消；烬锋雷闪持续 0.18 秒，前 0.12 秒保护，冷却 6 秒。

保护期间仍可收集影晶和进入终点；尖刺不会被清除，坠落失败边界仍有效。忍术、受伤和雷闪的保护各自计时，互不相加或覆盖。

收集影晶或击破敌人增加连击；2 秒内没有新事件或受到伤害时中断，最高连击保留到结算。

跳跃、翻绳、雷闪、拾取、技能和战斗均有短音效与碎屑反馈；上侧预警使用高音、下侧预警使用低音，首领弱点开放与技能重新就绪各有提示。受击与首领击破附带轻微震动和冲击闪光。震动只处理最终画面，HUD 保持稳定，镜头、碰撞体和固定弹道不受影响。准备页、局内、暂停与结算的反馈设置使用同一套开关；每次调整自动保存，重启后恢复。装备、成绩与反馈偏好共同保存至 `user://save.json`。详见 [音效与反馈](docs/FEEDBACK.md)。

移动端自动显示左侧翻绳键、右侧独立跳跃键 / 身法 / 武器 / 忍术和顶部暂停按钮，支持多指同时操作。跳跃键在钢索上侧起跳、下侧回到上侧、空中追加跳跃；翻绳键在上侧下翻、下侧上翻，空中点按立即快速落绳，长按只执行一次。按钮名称与冷却跟随实际状态，运行中收起右上角色、技能和武器说明，暂停遮罩显示忍术、身法和武器技能介绍。桌面按 `F3` 可切换触屏预览并用鼠标点按；也可使用 `-- --touch-controls` 启动。准备页、设置、暂停、重试与返回均可触摸操作。原型与桌面模拟验证已完成，Android 实机仍待验收。详见 [移动端触屏操作](docs/TOUCH_CONTROLS.md)。

## 成绩与存档

正式主线成功通关后，按收集与受击计算 1～3 星，独立记录无伤印、最高分单局快照、最快单局及各角色纪录。分数为 `1000 + floor(1000 × 收集数 / 总数) + max(0, 1000 - 150 × 受击次数)`，2200 分起二星、2600 分起三星；40/50 影晶、受击 1 次为 2650 分三星，无伤印另要求 0 受击。时间、击破、连击不影响主线星级。

关卡选择页可切换全角色 / 当前角色纪录。旧版评级、分数与装备保留，旧纪录显示“星级待挑战”，不伪造星级或无伤印；练习仍单独记录，不改变主线星级或解锁。失败、中途重试或返回准备不生成通关纪录。新存档为 v3：起始赠送 120，正式通关发放基础 / 收集 / 首通 / 新星 / 首次无伤 / 章节星数奖励，金额与领取账本、成绩和解锁一起保存。结算支持触摸查看奖励明细，准备页与地图显示余额。成长、商店及消费仍待实现，详见 [成绩与存档](docs/SAVE_SYSTEM.md)。

保存失败时，本次成绩和设置仍在内存有效，准备页、地图、设置面板与结算页提供“重试保存”；有未保存奖励时暂不开始新正式局，仍可免费练习。写入使用临时文件替换并保留上一份有效备份；主文件损坏或缺失时尝试恢复备份，均不可用时回退默认配置。旧版装备存档兼容，未知字段保留，较新版本不覆盖。详细规则见 [成绩、设置与存档](docs/SAVE_SYSTEM.md)。

## 关卡编排

路线由 `data/levels/fog_ridge_60s.tres` 配置，在 Godot 检查器中可编辑段落、提示、机关和影晶。

| 基础跑速时间 | 段落 | 内容 |
| --- | --- | --- |
| 0～10 秒 | 钢索入门 | 稀疏机关、上下翻绳与影晶引导 |
| 10～25 秒 | 上下交替 | 交替侧别，建立稳定节奏 |
| 25～45 秒 | 连续机关 | 同侧机关组合，可选跳跃跨越 |
| 45～60 秒 | 冲刺收尾 | 缩短机关间距，身法提供可选补救，末段奖励 |
| 约 60～100 秒 | 首领追逐 | 上下横扫、平行齐射、飞镖球、武器与角色技能、击破结算 |

跑酷段总计 29 个机关、50 个影晶、5 个钢索接触哨兵和 2 次屏幕右侧远程遭遇。下侧来袭在上下交替段触发，上侧来袭在连续机关段触发。跑酷段纯翻绳可无伤收齐；首领段结合飞镖球、J 武器与 K 月蚀斩击破。影晶高度绑定身位，数据检查覆盖机关、敌人、预计飞弹遭遇点之间的翻绳空间及同侧影晶间隔。详细编辑方法见 [关卡编辑说明](data/levels/README.md)。
